Diagramon dev3.0 · 界面原型

Rust + Tauri 2 + WebView2 的新客户端界面方案。AI 画图是第一公民，四种格式（Mermaid / Graphviz DOT / drawio / Excalidraw）共用一套工作区与画布手势，格式互转单向且理由透明，面板沿用 VS Code 的肌肉记忆。淡雅配色，明暗双主题。

1设计原则

五条原则决定每个控件的去留。原型里所有"看起来多出来的东西"都能在这五条里找到出处，找不到就该删。

AI 是第一公民，不是侧边挂件

旧版把 AI 塞在编辑器下方的折叠条里，新版纳为常驻右栏，与编辑器平级。三件事永远一键可达：描述生成（Ctrl+I）、识图（Ctrl+Shift+I）、审查改图。生成结果必须点「应用」才落进编辑器，可回退。

面板模型抄 VS Code，不发明

活动栏 / 侧栏 / 编辑区 / 右栏 / 底部面板五块，开合键位沿用 Ctrl+B、Ctrl+J、Ctrl+Shift+P、Ctrl+1~3。用户的肌肉记忆是资产，重学成本是负债。

文本型与画布型，两种承载说清楚

Mermaid / DOT 是文本：源码 + 预览可分屏，源码窗口可整块隐藏（Ctrl+3）。drawio / Excalidraw 是画布：画布即编辑器，没有分屏 —— 控件不藏起来装死，而是明确写「画布即编辑器」。

转换单向，不可用的方向给理由

Mermaid → drawio / Excalidraw / DOT 是单向的：结果另开标签页，原文件不动。反向（画布 → 语义）需要几何反推，计划 v3.1；转换中心把不可用方向列出来并写明原因，而不是藏起来让用户猜。

淡雅 = 低饱和 + 颜色自带解释

底色是冷灰白（不是纯白），强调色松绿，AI 用藕紫区分。语义色（成功/警告/错误）与四种格式标识色全局统一；凡用颜色表达状态的地方，旁边一定有文字或 title 说明阈值与成因。

明暗双主题：一处变量，全量生效

所有颜色只经 CSS 变量取值，切主题只改 <html data-theme>。预览里的 SVG 图形、代码高亮、画布点阵全部走同一套变量 —— 包括四个渲染页（mermaid / graphviz / drawio / excalidraw）也要跟着换色。

2布局解剖

五块工作区 + 标题栏 + 状态栏。每块都可独立隐藏并记住状态；隐藏不销毁（画布的撤销历史还在）。没有面包屑：文件路径在标题栏居中显示、在侧栏高亮，面包屑是第三次重复；它唯一不重复的信息（当前行所在的 subgraph / cluster）挪到了状态栏行列号旁边。

两处"显式占位"是硬约束。工作区四列与分屏三列都必须写死 grid-column：display:none 的元素不参与 grid 自动布局，隐藏侧栏或源码窗口后，剩下的面板会掉进第一列（宽 0）整块空白。原型里这两个 bug 都真实踩过，已写进注释。

3格式与承载

格式注册表是单一真源（真实实现里在 crates/app-core/src/format.rs）：扩展名、承载方式、能力位集中定义，UI 不维护第二份清单。

格式扩展名承载分屏AI 直出特有
Mermaid.mmd .mermaid页内渲染（mermaid.js 随包）源码 / 分屏 / 预览是转换的唯一源格式
Graphviz DOT.dot .gv页内渲染（wasm-graphviz 随包）源码 / 分屏 / 预览是六种布局引擎，状态栏切换、增量更新不重载 WASM
drawio.drawio自托管 embed 画布画布即编辑器经 Mermaid 转换文件是 mxfile XML；单一保存入口；autosave 回写正文
Excalidraw.excalidraw库型实例化画布画布即编辑器经 Mermaid 转换文件是场景 JSON；手绘风；字体随包零 CDN
画布手势四处一致：滚轮平移 · Shift+滚轮横向 · Ctrl+滚轮以光标缩放 · 拖拽平移 · 双击或 Ctrl+0 适应视图。缩放读数只在状态栏出现一处，避免同屏两个互相矛盾的数字。

4格式互转

三个入口：菜单「文件 → 转换为」、预览头「转换」按钮、侧栏「转换中心」。全部单向；结果另开标签页，原文件保持不动。

方向状态实现方式语义
Mermaid → drawio已实现drawio 自带解析器接管单向；画布改动不回写源码
Mermaid → Excalidraw已实现@excalidraw/mermaid-to-excalidraw，页内完成单向
Mermaid → DOT新增本地 AST 映射节点 → node，边 → edge，subgraph → cluster
DOT → Mermaid实验仅 flowchart 子集布局反推方向不定，record 形状跳过并报告
drawio → Mermaid计划 v3.1几何 → 语义反推转换中心列出并给理由，不藏
Excalidraw → Mermaid计划 v3.1手绘元素无稳定语义同上
不可用 ≠ 不存在。转换中心把六个方向全部列出：可用的给实现方式，不可用的给原因与计划版本。用户看到「计划 v3.1」比看到一个消失的菜单项更踏实。

6AI 第一公民

AI 面板是工作区的一等公民：常驻右栏、独立配色（藕紫，与强调色区分）、三个 tab 覆盖三种意图。

对话生成

  • 当前文档源码自动作为上下文，面板头标明来自哪个文件
  • 代码卡带格式徽章与行数，动作：应用 / 应用为 drawio / 回退 / 复制
  • 如实标出本次实际档位与信用点消耗（自动选档时由服务端回报）
  • 渲染失败把报错原文回修一次，第二次调用会在消息里注明

识图

  • 截图区域 / 选文件 / 粘贴三条路；>1568px 自动压缩
  • 图片只在内存：不落盘、不进会话记录，发送前有上传告知
  • 结果带置信度条（结构 / 文字 / 连线方向），低置信项明确提示核对
  • 画布型格式没有直出：先 Mermaid 再一键「应用为 drawio / Excalidraw」

改图（审查）

  • 只改局部，不重写整张图；建议逐条列出，可单条应用
  • 与「问题」面板联动：语法问题同时出现在两处，跳转同一行
  • 源码窗口右上角「AI」按钮 = 把当前正文送进改图 tab

9.1 运行时分工：哪些归 Rust/Tauri，哪些留在 WebView

一句话原则：摸"机器状态"的归原生，摸"渲染与交互"的归 WebView。四个渲染引擎（mermaid.js / wasm-graphviz / drawio / Excalidraw）全是 JS/WASM，只能在 WebView 里跑；反过来，密钥、磁盘、watcher、网络只允许 Rust 碰。

Rust / Tauri 原生（crates/）

  • 窗口与生命周期：创建/恢复、单实例、文件关联双击打开、更新器；Windows caption 按钮走 titleBarStyle: Overlay（原生），菜单仍自绘
  • 文件系统：打开/保存/另存、原子写、autosave 计时、最近文件、工作区扫描（资源管理器的树数据）、文件 watcher（notify → 事件推 WebView）
  • 搜索：全工作区文本搜索，Rust 流式回结果
  • 解析与诊断：mermaid / dot 的 AST（app-core）、校验行号、大纲树、当前作用域 —— 单一真源，WebView 只渲染不重算
  • 注册表与纯 Rust 转换：format.rs；Mermaid→DOT 的 AST 映射器
  • AI 网络层：reqwest + SSE 流式；BYOK 密钥存 DPAPI/钥匙串（永不进 WebView）；代理/重试/取消；信用点缓存；识图图片压缩
  • 截图区域：无边框 overlay 窗口 + 屏幕捕获
  • 写出出口：剪贴板 PNG、导出落盘
  • 设置持久化：settings.json（主题/密度/面板状态/分屏比例/每标签视图模式）

WebView（ui/）

  • 全部界面 chrome：五块工作区、标题栏菜单、命令面板、对话框、toast、状态栏 —— 原型里的一切
  • 编辑器：CodeMirror 6（高亮/光标/编辑）；诊断与大纲拿原生数据渲染
  • 文本型渲染：mermaid.js、wasm-graphviz（WASM）
  • 画布型承载：drawio embed、Excalidraw 实例；手势、浮动导出、缩放读数
  • 主题应用：CSS 变量 + 向四个承载页转发
  • 布局与键位：状态机、分发、显隐的工作副本（持久化归原生）
  • AI 渲染：流式展示、代码卡、置信度条、应用/回退
  • 库型转换：Mermaid→drawio（drawio 解析器）、Mermaid→Excalidraw（@excalidraw/…）—— 上游是 JS 库，进不了 Rust
  • 导出序列化：SVG serialize / canvas.toBlob，字节交原生落盘

10待拍板

原型跑出来的四个问题，都不影响开工，但影响细节。

① AI 面板默认开还是收

第一公民主张默认开；但 1280 宽以下会挤到编辑区。建议：≥1440 默认开，以下收成活动栏角标 + 一键展开。

② Mermaid→DOT 的 subgraph 语义

映射成 cluster 会丢 classDef 样式。建议：转换记录里注明「样式未迁移」，不静默丢。

③ 识图置信度要不要展示

展示了能解释「为什么这节点名字怪」；不展示界面更干净。建议：默认折叠成一行「2 处低置信，点击核对」。

④ 暗色下画布底

drawio / Excalidraw 上游默认白纸。建议：承载页注入主题变量把画布底换成 --canvas-bg，导出仍按用户选择（透明/白/跟随）。
