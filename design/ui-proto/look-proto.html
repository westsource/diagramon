交互与落盘约定（实施时照此）

① 控件只在文本型且有选项的格式上出现：Mermaid = 外观 + 布局两颗（外观：auto / classic / neo / handDrawn； 布局：dagre / elk），DOT = 6 种布局引擎，D2 = dagre / elk / tala；drawio / Excalidraw 无此按钮。
② 点选即写 d.layout（复用现有 state.setLayout / doc_set_layout，与状态栏旧入口 同一字段、互相同步；Mermaid 的外观与布局两项的存储编码实施时定：同字段分节或加 d.mlook）→ 立即重渲染； 按钮文案与预览副标题同步更新。
③ Mermaid 渲染映射：外观 → initialize({ look })；布局 → initialize({ layout })。 elk 需要 vendor @mermaid-js/layout-elk@1.0.1（ESM-only，照 fetch-excalidraw 的 npm install + esbuild IIFE 模式打离线包，mermaid.registerLayoutLoaders(elkLayouts) 注册）； 未注册时菜单里 elk 置灰并提示。frontmatter config 仍然最高优先。
④ 状态栏旧入口保留（同一数据源），后续可再议去留。
