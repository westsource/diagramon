# Diagramon - 多格式图表编辑器

[English](README.md)

一个**本地优先**的多格式图表编辑器：**Mermaid**、**Graphviz DOT**、**D2**、**drawio**、
**Excalidraw** 五种格式在同一个窗口里编辑、实时预览、互相转换，AI 走你自己的通道。
渲染、校验、转换全部在本机完成，不会把图发到任何服务器。

版本 **3.11.2** · 官网 <https://www.diagramon.com>

## 它解决的问题

**1. 一张图要在五个工具之间搬。** 写 Mermaid 用编辑器、看效果开 mermaid.live；画到一半想手拖一下，
得换 drawio 从头再来；DOT 和 D2 又是另外两个在线渲染页。每次搬都要复制粘贴、重排、再对一遍样式。

**2. 在线图表工具要你把东西传上去。** 架构图、流程图里往往写着真实服务名、内网域名、客户名。
在线编辑器先上传再渲染，等于先泄露再出图；纯离线工具又普遍没有 AI，想润色一句得自己写提示词
再手工贴回。

**3. AI 用得不放心。** 图表工具的 AI 通常把整份文档默默发到某个固定服务，发什么、发多少、算几毛
钱都看不见；自家模型或自建网关接不上；密钥存在浏览器里。

**4. 画布格式的文件没法进版本库。** 拖出来的图是压缩包或一坨 JSON，改了看不出差在哪，
和代码放同一个仓库里没法评审。

**5. 转换工具会把图转坏，而且不说。** 转完少了边框、丢了样式、箭头方向反了，工具却报"成功"。

## 我们的做法

1. **一个窗口、五种格式、五种格式互转**：文本格式与画布格式并排打开，Mermaid / DOT / D2 可以转成
   drawio / Excalidraw 继续拖，D2 还能带着几何转成 drawio。
2. **全部在本机渲染**：Mermaid、Graphviz、D2 的引擎随安装包分发（WASM / 打包 JS / 官方 wasm），
   drawio 与 Excalidraw 用的是随包的官方运行时。**不起子进程、不发外部请求**，断网可用。
3. **磁盘上永远是文本**：`.drawio` 落盘是 mxfile XML，`.excalidraw` 落盘是场景 JSON —— 画布只是它的
   一个视图，改动照常可 diff、可进 git、可评审。
4. **AI 走你选的通道**：会员用官方网关（凭据是登录令牌，不用填 Key），或 BYOK 直连自己的
   OpenAI 兼容服务 / Ollama / 自建端点。密钥只存在 Rust 进程内（Windows DPAPI），前端拿不到。
   只有你主动使用 AI 时，选中的内容才会发往你选定的上游。
5. **有损转换必须说清楚**：每个结果都带一份"没迁移什么"的清单，转换后还会对账节点与连线数量，
   少了就告诉你少了多少。

## 功能特性

### 编辑
- **五种格式、多标签**：`Mermaid`（`.mmd` / `.mermaid`）、`Graphviz DOT`（`.dot` / `.gv`）、`D2`（`.d2`）、
  `drawio`（`.drawio`）、`Excalidraw`（`.excalidraw`）并排编辑；标签溢出时滚入视野、滚轮横滚、两端渐隐，
  `Ctrl+Tab` / `Ctrl+PgUp` 循环切换
- **引擎级语法校验**：问题由图形引擎自己解析后报出，给真实行号（Mermaid 还带列号）；点问题跳到源码
  对应位置，出错行画红线；D2 走随包 wasm 真编译，drawio / Excalidraw 做结构校验；引擎缺失或文档超大时
  明确标注**降级**，绝不把"没校验"当"通过"
- **大纲与当前作用域**：从正文解出节点与 `subgraph` / `cluster` / D2 容器树，点击跳到源码并滚到可见处；
  drawio / Excalidraw 有分组与图形节点大纲，点击直接在画布上选中定位；状态栏显示光标所在容器
- **查找替换、撤销重做、右键菜单、命令面板**（`Ctrl+Shift+P` / `F1`）
- **Tab 与主流编辑器一致**：空选区补空格到下一个制表位，选区整块缩进、`Shift+Tab` 反缩进，一次按键一步撤销
- **大文档护栏**：超过 400 KB / 5000 行的图在打开、保存、渲染前各确认一次，不静默把引擎拖死

### 预览与导出
- **源码 / 分屏 / 预览三态**（`Ctrl+1/2/3`），源码窗格可整块隐藏
- **统一手势**：滚轮平移、`Shift+滚轮` 横向平移、`Ctrl+滚轮` 以光标为锚缩放、拖拽平移、双击适应视图
- **适应视图适配的是内容**：按图自身包围盒两维适配并居中（有意忽略 drawio 的页面框）；窗口或面板尺寸
  变化后自动重新适配（可在设置里关掉）；状态栏只显示当前视图的缩放值
- **布局与外观随选随切**：DOT 六种布局、D2 三种（`dagre` / `elk` / `tala`）、Mermaid `dagre` 与 `elk`；
  Mermaid 外观 `classic` / `neo` / `handDrawn`。选项就在预览顶栏，**按文件记住**，点完立即重渲染
- **导出**：PNG（倍率可选）或复制到剪贴板；位图带着与预览一致的底色，粘贴到白底文档里不会像一片空白；
  图大到越过浏览器画布上限时自动压倍率并说明，而不是给一张空图
- **渲染产物先消毒再挂载**，主界面文档带禁止内联脚本的 CSP

### 画布编辑（drawio / Excalidraw）
- **画布就是编辑器**：直接拖、直接连，不提供源码/分屏三态
- **改动自动回写**正文并打脏标，保存前先向画布取一次最新内容，不会输给画布自己的 autosave 去抖窗口
- **撤销历史不丢**：切换标签不会销毁承载页
- **离线自带**：两个运行时都随安装包分发，零外部请求

### 格式转换
- **可转方向**：`Mermaid → DOT` / `Mermaid → D2` / `DOT → D2` / `Mermaid → drawio` /
  `Mermaid → Excalidraw` / `D2 → drawio`（保几何，转出来还能继续拖拽编辑）
- **单向语义**：产物另开标签页，原文件字节不变
- **有损逐条说明**：结果附 `notes` 列出哪类信息没迁移，对话框直接显示
- **转换后数量对账**：自动数两侧节点与连线，少了就报"少 N 个节点、M 条连线"；数不出来就明说对不了账
- **AI 增强转换**（可选，默认关）：结果有损或校验失败时出现入口，一次初改 + 最多 3 轮校正，连续两轮
  同样错误提前止损，首次使用先提示将外发什么
- **`Mermaid → drawio` 可选 ELK 重排**；不可用方向照样列出并写明原因
- **兜住以前会转坏的细节**：边端点标记、DOT 关键字同名节点、D2 线宽范围、圆角标签里的括号等

### 工作区与文件
- **打开文件夹**：资源管理器树（只收本应用认识的扩展名，跳过 `.git` / `node_modules` / `target`），
  可按名称或修改时间正/倒序、文件夹优先；中文名按拼音排序、数字按数值比较（「图 2」在「图 10」前）
- **全工作区搜索**（`Ctrl+Shift+H` / `Alt+2`）：流式返回结果、带行列号、可跳转、可取消
- **文件监视**：外部改动自动跟上；与本地未保存内容冲突时给一条横幅让你选「用磁盘版本 / 保留我的」
- **单实例 + 文件关联**：双击图表文件由已有窗口打开，不新起进程
- **自动保存默认关闭**，可在设置里开启（500–60000 ms 可调）；未落盘内容有草稿仓，坏一份不连累其它
- **路径守卫**：工作区内的新建/重命名/删除永远经根目录校验，拒绝 `..` 与绝对路径；可开「只允许在
  工作区内读写文件」

### AI 助手
- **一条时间线，四种意图**：生图、识图、改图、解图共用一条按时间排序的对话；每条消息带意图，
  发送前用四档滑块明示，点任意一档手动覆盖，发送后自动清掉
- **意图自动判定**：设置里可选 `自动 / 官方 / 自定义 / 关闭`，失败或低置信回退本地规则，绝不阻塞发送；
  判定期间发送按钮锁定，双击不会重复计费
- **输出格式下拉**：跟随当前 / Mermaid / DOT / D2 / drawio / Excalidraw；目标格式不同则新建对应标签页
- **两种凭据，界面上分开**：会员云网关（凭据是登录令牌）与本地 BYOK（OpenAI 兼容 / Ollama / 自定义）
- **识图四种入口**：选图片文件、弹窗里按 `Ctrl+V` 粘贴、把文件拖进弹窗，或**框选屏幕一块区域**；
  最多两张图对比，只在内存里压到 ≤1568px，不落盘、不进会话记录
- **外部文件当上下文**：最多 8 份、单份 256 KiB、仅 UTF-8 文本；参考文件与"当前图表源码"在提示词里
  分开措辞，模型不会把参考资料当成要重写的正文
- **改图按整篇走**：上行完整源码、要求返回完整源码，「应用」不会只剩半张图；取最后一个非空代码围栏
- **AI 只改它自己写的那一版**：渲染失败自动修正只在正文仍是 AI 刚落的那版时触发，你手改出的错不会被覆盖
- **解图只读且按排版显示**：Markdown 渲染、流式边写边渲染、可切预览/源码；模型输出当纯文本处理，
  不执行内联 HTML/脚本，`javascript:` 链接不可点
- **单条消息可操作**：重新生成 / 编辑后重发 / 删除 / 拷贝，不用清空整段对话
- **真的记得上文**：对话轮次带进下一次请求（自动裁剪，最新一轮永远保留）
- **会话历史按文档持久化**：本机存储、重启还在；「全部」页签按 文档 / 草稿 / 已失联 三种归属列出所有
  会话（未保存文档的也在内），可搜索、导出 Markdown、清理 30 天前的失联会话；草稿与失联不会自动删除
- **思考过程可见可收**：思考型模型的推理实时显示、收尾自动收起、可展开读全文，并随会话一起落盘
- **长期记忆（可选）**：AI 提议记住你的偏好与术语，先落「待确认」，确认后才生效，全部存本机
- **受控工具循环（试验）**：AI 回答前可"读文档 → 查语法 → 校验"，最多 5 步，只作用于内存文档模型，
  不接触文件系统、shell 或网络
- **用量如实标注**：只累计供应商实报的 token，未回报显示 `—`，不显示 0，也不掺本地估算
- **密钥永不进前端**：Key 只存在 Rust 进程内（Windows DPAPI 按用户加密），前端只拿 `has_key` 与掩码

### 云端
- **登录令牌只进凭据库**（DPAPI），过期静默续期，重启不再要求重新登录
- **账户视图**：邮箱、昵称、套餐、角色、存储用量，以及 AI 权益与信用点额度
- **云端文档**：目录树（空目录也在）、筛选、打开；保存到云端可挑目录、可新建子目录
- **网关 auto 档位**：由服务端按能力与图片输入需求路由
- **`base_url` 留空 = 云端整体关闭**，一切照旧离线工作
- **不做假数据**：未配置就写"去配置"，未登录就写"未登录"，余额从不伪造

### 设置与更新
- **明暗双主题 + 多套强调色**，全部颜色走 CSS 变量
- **面板状态记住**：侧栏 / AI / 底部面板的开合与宽度、源码窗格比例、最近文件，重启即还原
- **中英双语**（`zh-CN` / `en-US`），两侧词条键集完全一致
- **内置自动更新**：minisign 签名校验；"已最新 / 有新版本 / 出错"三种结果如实呈现，检查失败绝不说成
  "已是最新"
- **关闭到托盘（可选）**：✕ 只隐藏窗口，托盘图标可唤回或退出
- **Mermaid 默认外观**：文档没选外观时的全局兜底

## 技术栈

- **语言 / 框架**：Rust（2021 版次）+ Tauri 2，界面跑在系统 WebView（Windows 上是 WebView2）
- **前端**：无框架、无构建链、零 CDN；编辑器是随包的 CodeMirror 6
- **渲染**：Mermaid（打包 JS）· Graphviz（WASM）· D2（官方 wasm 构建）· drawio（裁剪运行时）·
  Excalidraw（本地打包）—— 全部随安装包分发，本地运行
- **AI**：Rust 侧 `reqwest` + SSE 流式，凭据走 DPAPI
- **打包**：NSIS 安装包，渲染运行时与前端资源一并入包

架构与设计决策（同源承载页与自定义协议、运行时分工、阈值来历、转换语义、发版纪律）见
[《客户端设计与技术决策》](https://github.com/westsource/diagramon_service/blob/main/docs/diagramon客户端设计与技术决策.md)。

## 运行环境

- Windows 10 / 11 64 位，需要 WebView2 运行时（Win10/11 通常已预装）
- 不需要 VC++ 运行库：release 已静态链接 CRT
- 渲染与画布运行时（约 105 MB）和前端资源都在安装包里，装完即用，无需额外下载
