### 安全修复

- **内部协议路径穿越（高危，已实证）**：`dgm` 资产协议的目录检查只按 `/` 识别 `..`，
  而 Windows 把 `%5C` 解码出的反斜杠也当分隔符 —— 构造特定 URL 可读到挂载目录之外的任意文件；
  绝对路径（`C:/…`）还会让路径拼接整体替换基目录。现在反斜杠、`..` 段、绝对/带根路径
  三种形态全部拒绝，并加了回归测试钉死。
- **渲染产物消毒（第二道防线）**：预览区不再把渲染引擎的 SVG 直接塞进页面 —— 先在惰性容器里
  剥掉脚本、内嵌对象与事件属性，再挂载。三套渲染引擎各自的转义纪律之外，应用自己也有了兜底。
- **内容安全策略（CSP）**：主界面启用了 CSP，脚本只允许本应用自身与 wasm 运行所需，
  不再放行内联脚本 —— 即使某天上游渲染库被曝出注入类漏洞，可利用面也大幅收窄。
- **导出落盘加扩展名白名单**：导出命令只允许写 png / jpg / svg / webp 等图片格式，
  不再可能被借道写入可执行文件。

### 其它修复

- 保存时的临时文件命名不再可能互相覆盖（同一目录下 `同名.mmd` 与 `同名.drawio` 并存的场景）。
- 命令行打开文件与单实例唤起两条入口的扩展名过滤统一了。
- 云端文档 id 拼进请求路径前做百分号编码；AI 面板的图片缩略图地址与全部文案转义补齐了单引号；
- 导出时点了「取消」就如实取消，不再把文件写进一个写死的开发路径。

# English

**Diagramon {{version}}** is a security-hardening release: a full code audit found and fixed 9 issues,
the most important being a path traversal in the internal `dgm` protocol that a maliciously crafted
diagram file could theoretically use to read local files outside the mounted asset directories.
All 9 audit findings (1 high, 2 medium, 6 low) are fixed in this version. **All users should update.**

| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Security fixes

- **Protocol path traversal (high, proven with a working repro)**: the `dgm` asset protocol's
  directory check only recognized `..` segments separated by `/`, while Windows also treats the
  backslash produced by decoding `%5C` as a separator — a crafted URL could read arbitrary files
  outside the mounted roots; absolute paths (`C:/…`) even replaced the base directory entirely.
  Backslashes, `..` segments and absolute/rooted paths are now all rejected, with regression tests.
- **Sanitization of rendered output (defense in depth)**: the preview no longer inserts the engines'
  SVG straight into the page — scripts, embedded objects and event-handler attributes are stripped
  in an inert container first. Beyond each engine's own escaping discipline, the app now has a
  backstop of its own.
- **Content Security Policy**: the main window now runs under a CSP that allows only the app's own
  scripts plus what WebAssembly needs — no inline scripts. If an upstream rendering library ever
  ships an injection vulnerability, the exploitable surface is much smaller.
- **Extension whitelist for exports**: the export command can only write png / jpg / svg / webp
  style image files; it can no longer be abused to drop executables.

### Other fixes

- Save-time temp files can no longer overwrite each other (`same-name.mmd` next to
  `same-name.drawio` in one folder).
- Command-line file opening now applies the same extension filter as the single-instance path.
- Cloud document ids are percent-encoded before being placed in request paths; the AI panel's image
  thumbnails and all templated text now escape single quotes as well.
- Cancelling the export dialog now honestly cancels, instead of writing to a hard-coded dev path.
