### 本次亮点

- **渲染失败自动修正**：AI 生成的图渲染报错时，把上游报错原文自动回喂给模型再修一次
  （默认开启，可在设置里关；这是第二次真实调用，会计入用量）。
- **真正的多轮对话**：以前每一轮请求都从零开始、记不住前面说过什么；现在对话轮次会带进请求
  （自动按 8 轮 / 6000 字符裁剪，最新一轮永远保留），你可以接着上一句继续改图。
- **会话按文档持久化**：对话历史按文档存在本机，重启后还在；「历史会话」对话框显示的是
  真实轮次，清空只影响当前文档。图片永不落盘。
- **长期记忆（可选）**：AI 可以提议记住你的偏好与术语（配色、默认流向、命名习惯……），
  产物先落在「待确认」，**你确认后才生效**；也可以在记忆管理对话框里手动增删改。
  全部存本机、随请求注入、可在设置里整体关闭。
- **受控工具循环（试验）**：设置里打开后，AI 回答前可以先「读文档 → 查语法 → 做校验」，
  循环最多 5 步。工具只作用于内存中的文档模型，**绝不接触文件系统、shell 或网络**。
  打开后改走非流式多步调用（不再逐字输出），每一步都计入用量——所以默认关闭，由你决定。
- **导出 PNG 修复**：节点标签里带 `<br>`（换行）的图，导出 PNG 会报「位图栅格化失败」——
  现在已修复，这类图可以正常导出了。

# English

**Diagramon {{version}}** lands all five stages of the AI capability plan in one release:
automatic render-failure retry, real multi-turn conversations, per-document conversation history,
optional long-term memory, and an (experimental, opt-in) controlled tool loop — plus a fix for
PNG export failing on labels that contain `<br>`.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Automatic render-error retry**: when an AI-generated diagram fails to render, the upstream error
  text is fed back to the model for one automatic fix attempt (on by default, toggleable in Settings;
  it is a second real call and counts toward usage).
- **Real multi-turn conversations**: every request used to start from scratch; conversation turns are
  now included (auto-trimmed to 8 turns / 6000 chars, newest turn always kept), so you can keep
  refining a diagram across messages.
- **Conversation history, persisted per document**: histories are stored locally, keyed by document,
  and survive restarts; the "History" dialog shows real turns, and clearing affects only the current
  document. Images are never written to disk.
- **Long-term memory (optional)**: the AI can propose to remember your preferences and terminology
  (colour scheme, default flow direction, naming habits…). Proposals land as **pending** and only
  take effect after you confirm them; you can also add, edit or delete entries in the memory dialog.
  Everything is stored locally, injected into requests, and can be turned off entirely in Settings.
- **Controlled tool loop (experimental)**: when enabled in Settings, the AI may "read the document →
  check grammar → validate" before answering, for at most 5 steps. Tools only operate on the
  in-memory document model — they **never touch the filesystem, shell or network**. Enabling it
  switches to non-streaming multi-step calls (no more word-by-word output) and every step counts
  toward usage — which is why it is off by default.
- **PNG export fixed**: diagrams whose node labels contain `<br>` (line breaks) used to fail with
  "bitmap rasterization failed"; they now export correctly.

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw

actively use AI, and then only the endpoint you chose.
