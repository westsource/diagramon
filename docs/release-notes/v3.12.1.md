### 本次亮点

- **源码窗格的行首色块**：会被上色的节点，在它首次出现的那一行左侧点一个色块 —— 颜色就是它真会被
  染成的色（由后端按与渲染完全相同的判定给出，不是前端猜的）；同一个节点只标一次，长图不刷屏。
- **手写颜色看得见**：带自己的 `style` / `fillcolor`（因此会被「仅未着色」跳过）的节点画**虚框**，
  悬停写明「手写色，保持」—— 不会让人以为它也会被上色。
- **悬停即查**：`A · 入口` 加上 `#d4e3ed / #4ab5a0`，角色与色值都在，不用去预览里点。
- **行底色（默认关）**：「格式化」旁边多了一个「行底色」按钮，开启后给会被上色的行铺一层极淡的角色色；
  设置 → 编辑器里也有同一个开关。它画在**文字下面**，不会给代码蒙色，也不改正文。
- **标注是只读的**：色块与行底色都不进撤销栈、不改文件、不标脏。

### 修复

- **连线开关不再把颜色写进缓冲区**：3.12.0 里切换「连线跟随配色」会把配色烘焙进正文并标脏，
  与"颜色只在预览里"的模型相悖；现在只重画预览（状态栏也从"已重跑当前文档"改成"预览已更新，正文未改"）。
- 设置 → 编辑器里「路径守卫」与「快捷键」两条说明贴在一起，已加缝隙。

# English

**Diagramon {{version}}** brings the palette into the source pane: you can see which lines will be coloured, without switching to the diagram.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **A swatch on the line where each node appears** — every node that will be coloured gets a swatch on the
  left of its first line, in exactly the colour it will render with (computed by the backend with the same
  rules the renderer uses, not guessed in the front end). One swatch per node, so long diagrams stay readable.
- **Hand-written colours are visible too** — a node carrying its own `style` / `fillcolor` (and therefore
  skipped) gets a **dashed frame** and a "hand-written, kept" tooltip, so it never looks like it will be recoloured.
- **Hover to inspect** — `A · entry` plus `#d4e3ed / #4ab5a0`: role and value, without opening the preview.
- **Row tint (off by default)** — a new "Tint rows" button next to Format, and the same switch under
  Settings → Editor. It paints a very faint role colour **behind the text**, so code never looks washed out,
  and it never touches the document.
- **The overlays are read-only** — no undo entries, no file changes, no dirty flag.

### Fixes

- **The edge switch no longer bakes colours into the buffer** — in 3.12.0 toggling "edges follow the palette"
  wrote the palette into the document body and marked it dirty, contradicting the preview-only model; it now
  only redraws (the status line says "preview updated, source untouched").
- Two adjacent notes in Settings → Editor were touching; they now have a gap.

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>
