### 本次修复

- **AI 长思考不再被 5 分钟总超时掐断**：以前任何一轮 AI 对话/改图只要总时长超过 5 分钟
  （思考型模型很常见）就会被客户端自己的超时硬掐，报「网络请求失败：error decoding
  response body」。现在流式对话放宽到 30 分钟兜底，并新增**读空闲检测**（连续 90 秒收不到
  任何字节才判连接卡死）——慢而活着的流不再被误杀，真正卡死的连接 90 秒内就会报错。
- **断流不再丢思考内容**：以前思考内容已经返回、正文还没生成就断线时，已收到的思考会被
  一起丢掉、只报一句网络错误。现在会给出「连接中断：思考内容已收到，但正文还没生成就
  断开了，请重试」的明确提示。
- **瞬时网络失败自动重试一次**：请求没能送达（一个字都没收到）的网络失败会自动重试一次；
  已经开始生成的失败不会自动重试——那会向上游重复计费，重试与否由你决定。
- **对话配色跟随主题强调色**：我方气泡与头像不再固定为一种绿色，改为跟随当前主题的
  强调色（明暗主题各取各的）；用户头像与「账户」侧边栏的账户头像同一画法。

# English

**Diagramon {{version}}** is a stability release: it fixes AI streams with long thinking phases being
killed by the client's own timeout (reported as "network request failed: error decoding response
body"), makes stream interruptions more honest about what was received, and follows the theme
accent color for chat bubbles.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Fixes

- **Long AI thinking no longer killed by the 5-minute timeout**: any AI chat or image-edit round
  whose total duration exceeded 5 minutes (common for reasoning models) was cut off by the
  client's own timeout with "network request failed: error decoding response body". Streaming
  requests now get a 30-minute overall deadline plus an **idle-read detector** (a connection is
  declared stalled only after 90 seconds with no bytes at all) — slow-but-alive streams are no
  longer killed, and a genuinely stuck connection errors out within 90 seconds.
- **Interruptions no longer discard the thinking content**: when reasoning had already arrived but
  the answer never did, the received thinking used to be thrown away with a bare network error.
  You now get a clear message: "connection interrupted: thinking content was received, but the
  answer was not generated before the stream ended — please retry".
- **Auto-retry once for transient network failures**: when a request never got through (not a
  single byte received), it is retried once automatically; failures after generation has started
  are never auto-retried — that would double-bill the upstream, so retrying stays your call.
- **Chat colors follow the theme accent**: your chat bubbles and avatar no longer use a fixed
  green — they follow the current theme's accent color (light and dark each get their own);
  the user avatar is drawn the same way as the account avatar in the sidebar.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>
