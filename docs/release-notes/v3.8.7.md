### 本次亮点

- **修好「应用后对话消失」**：没有任何标签页时用 AI 生成，再点「应用到编辑器」，那段对话以前会从面板里
  整个消失（关掉新标签页又原样冒出来）。现在它会跟着产物落到新标签页里，关掉标签页也不会留下幽灵副本。
- **AI 面板新增「拷贝源码」**：助手回复的头部多了一颗「拷贝源码」，一次拷走这条回复产出的全部源码
  （多个代码块按空行拼接；没有代码块就拷回复正文）。代码卡片上的单块「复制」照旧。
- **拷贝不再骗人**：写不进系统剪贴板时会明确提示失败，不再一律弹「已复制」。
- **供应商次序可调**：AI 设置里每个供应商卡片多了「上移 / 下移」，保存后 AI 面板与菜单栏的模型下拉、
  「默认模型」下拉都按这个次序排（同一供应商内的模型顺序不变）。
- **默认输出上限改为 500k**：新添加的供应商默认 `最大 Tokens` 是 500,000（仍可随时改，上限 1,000,000）。
  上游实际能接受多少仍由供应商/模型决定，超出时上游会报错。

# English

**Diagramon {{version}}** is a patch focused on the AI panel: the conversation no longer disappears after
"Apply to editor" when no tab was open, plus copy, provider ordering and a new default output limit.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **"Conversation disappears after apply" is fixed**: with no tab open, generating a diagram and clicking
  "Apply to editor" used to wipe the conversation from the panel (and closing the new tab brought it back).
  The conversation now follows the result into the new tab, and no ghost copy is left behind.
- **New "Copy source" in the AI panel**: each assistant reply now has a "Copy source" button in its header
  that copies everything that reply produced (multiple code blocks joined by a blank line; the reply text
  when there is no code block). The per-card "Copy" button still copies a single block.
- **Copy tells the truth**: when the system clipboard cannot be written, you get a failure toast instead of
  a fake "Copied".
- **Provider order is adjustable**: each provider card in AI settings has "Move up / Move down"; on save the
  model dropdowns (panel and menu bar) and the "Default model" list follow that order (models inside one
  provider keep their order).
- **Default output limit is now 500k**: newly added providers default to `max tokens = 500,000` (still
  editable, cap 1,000,000). How much an upstream actually accepts is still up to the provider/model.

### Fixes

- "AI result → editable canvas" reported "conversion failed" even after landing successfully (the success
  path did not carry an `ok` flag).

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. Users on an older version
will be offered this release via **Help → Check for updates** (the update package is this same
installer; its signature is in `latest.json`).

> This installer is **not yet Authenticode-signed**, so Windows SmartScreen may show a warning.
