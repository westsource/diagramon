### 本次亮点

- **「格式化」按钮 / Shift+Alt+F 现在真的重排源码**，不再只是抹掉行尾空格：
  - **Mermaid**：`subgraph…end`、序列图的 `loop/alt/opt/par/rect/critical/break/box…end`、
    `else/and/option`、class / state / er 的花括号，统一缩进到 4 空格；
  - **Graphviz DOT**：按词法重排 —— 一行一条语句、属性表内联、子图缩进，一行式
    `digraph G{a->b;b->c}` 会展开成可读的多行；

- **只动空白，不动语义**：字符串、HTML 标签、跨行引号标签、Mermaid 的 YAML frontmatter、
  D2 的 `|md` 块字符串都逐字节保留；DOT 的注释与 `#` 行也原样搬运。
- **不假装修了一遍**：源码本来就规范时，状态栏会如实说「已是规范格式」，不会标脏。
- **可撤销**：整块替换走编辑器的正常事务，Ctrl+Z 能退回格式化之前；落盘仍跟随你的自动保存设置。

# English

**Diagramon {{version}}** turns "Format source" from an empty button into a real formatter.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **The Format button / Shift+Alt+F now actually reformats the source**, no longer just trimming
  trailing whitespace:
  - **Mermaid**: `subgraph…end`, sequence `loop/alt/opt/par/rect/critical/break/box…end`,
    `else/and/option`, and class / state / er braces are all indented to 4 spaces;
  - **Graphviz DOT**: lexer-level layout — one statement per line, attribute lists inlined,
    subgraphs indented; a one-liner like `digraph G{a->b;b->c}` expands into readable lines;
  - **D2**: brace levels are indented to 2 spaces.
- **Whitespace only, semantics untouched**: strings, HTML labels, multi-line quoted labels,
  Mermaid YAML frontmatter and D2 `|md` block strings are preserved byte for byte; DOT comments
  and `#` lines are carried over verbatim.
- **No fake "formatted"**: when the source is already canonical, the status bar says so and the
  document is not marked dirty.
- **Undoable**: the whole-document replacement goes through the editor's normal transaction, so
  Ctrl+Z returns to the pre-format text; saving still follows your auto-save setting.

### Fixes

- **"Format source" was never really implemented**: the button and `Shift+Alt+F` only trimmed
  trailing whitespace, so on most documents they did nothing. This release adds the Rust-side
  formatter and wires it to the button, the shortcut and the command palette.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer
