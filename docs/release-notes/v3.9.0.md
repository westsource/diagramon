### 本次亮点

- **转换报告**：转换记录里能展开看「结构 / 几何 / 样式」三层保真度、产物计数（节点 / 边 / 容器 / 页 / 标签）、引擎、耗时、布局与主题，以及逐条降级说明（样式近似、形状退化、端点标记未迁移……）。切到英文时这些说明也跟着变。
- **转换中心按真实数据画徽章**：每个方向取**最近一次成功转换**的报告；还没跑过的方向显示三个灰点并写明“还没有样本”，不预估。
- **AI 能真正“解释这张图”**：空态里的「解释当前这张图」会直接发一轮解释请求（3–8 句自然语言，不出代码块、不出现“应用”按钮），不再只是换个输入框。
- **用量按场景分组**：生成 / 识图 / 改图 / 解释 / 工具循环 / 记忆提取各自记账；工具循环多步的 token 不再全部丢掉，记忆提取的调用也不再是“幽灵调用”。

### 修复

- **转换失败不再留下一个空画布**：引擎取不到产物时关掉刚建的空标签页，并在转换记录里留一条可追溯的失败。
- **不可用的转换方向不再装扮成可用**：DOT → Mermaid 之前声明“能转”但实际报错，现在注册表与执行器说同一句话，转换中心把它标成实验方向并给出原因。
- **ELK 加载失败不再装作切换成功**：回退 dagre 时顶栏会说明原因，输出面板也留一条记录；离线包加载失败不会再被静默吞掉。

# English

**Diagramon {{version}}** turns conversion from a vague hint into a report you can check: how faithful structure, geometry and style are — and every single item that was lost.

### Downloads

| Option | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Supports **built-in auto-update**; fetches the WebView2 runtime if missing |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

Portable notes: the ZIP contains `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\` — they
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs nothing extra installed: no Node.js, no Chrome, no VC++ redistributable (the exe links the
CRT statically); only the WebView2 runtime that ships with Windows 10/11. “Check for updates” still
finds new releases, but applying one downloads the **installer** (it does not replace the portable
folder in place) — to stay portable, download the new ZIP and overwrite.

### Highlights

- **Conversion report** — expand a record to see the three fidelity layers (structure / geometry / style), output counts (nodes / edges / containers / pages / labels), engine, elapsed time, layout and theme, plus every degradation (approximate styling, fallback shapes, dropped endpoint markers, …). All of it follows the UI language.
- **The conversion center shows measured badges** — each direction uses the **latest successful** report; directions without a sample show three hollow dots and say “no sample yet” instead of estimating.
- **“Explain this diagram” actually explains** — the empty-state button now sends a dedicated explain request (3–8 sentences, no code fence, no Apply button) instead of just switching tabs.
- **Usage grouped by scene** — generate / vision / review / explain / tool loop / memory extraction are accounted separately; multi-step tool loops no longer drop all their tokens, and memory extraction no longer produces “ghost calls”.

### Fixes

- **A failed conversion no longer leaves an empty canvas** — when the engine returns nothing, the just-created tab is closed and a traceable failure is recorded.
- **Unavailable directions no longer pretend to work** — DOT → Mermaid used to be advertised but errored; the registry and the executor now say the same thing, and the conversion center marks it experimental with a reason.
- **ELK load failures are no longer silent** — falling back to dagre is stated in the status bar and recorded in the output panel.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid / Graphviz DOT / drawio /
Excalidraw, all editable with live preview, plus AI for generation, review and image recognition.
Rendering and validation work offline — only the AI features you explicitly use send code or images
to the upstream you choose.

Website: <https://www.diagramon.com>

- WebView2 runtime (usually preinstalled; the installer fetches it when missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all ship with the app
