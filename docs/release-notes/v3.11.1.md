### 本次亮点

- **官方 SystemOne**：会员登录后，意图判定默认走 Diagramon 官方服务，客户端不再需要自己配 Key。
- **自定义仍保留**：设置页可选 `自动 / 官方 / 自定义 / 关闭`；显式选过自定义后，登录不会覆盖你的配置。
- **官方不暴露密钥**：官方模式只带登录令牌调用服务端，不读取本机判定密钥；失败、未登录、无会员权限都只回退本地规则，不阻塞发送。
- **自动状态更干净**：判定成功才显示「自动判定 + 置信度」；未判定/超时/关闭时整个状态隐藏，不再出现「回退」。
- **会话格式归一**：每轮只写 `intent`，旧文件的 `tab` 读取时自动迁移；历史会话不再依赖已删除的页签概念。
- **判定更省**：面板收起时不请求；同一句话的并发判定复用一个请求；改端点/模型/阈值后旧结论立即失效。

### 修复

- 自动修正轮引用了已删除的 `retryCtx.tab`，导致修正消息丢失意图标记；已修复。
- 意图判定未完成时重复点击发送会重复发起同一句话；判定期间发送按钮已锁定。

# English

**Diagramon {{version}}** makes SystemOne part of membership: signed-in members use the official
classifier by default, while custom providers remain available. The conversation schema also gets
a one-way normalization.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Official SystemOne**: signed-in members classify intents through Diagramon's official service
  by default, with no local key to configure.
- **Custom still available**: Settings offers `Auto / Official / Custom / Off`; an explicit custom
  choice is not overwritten by signing in.
- **No key exposure in official mode**: it calls the server with the login token and never reads the
  local classifier key. Failures, signed-out state and non-member state all fall back to local rules
  without blocking sending.
- **Cleaner auto status**: “Auto-detected + confidence” appears only on a successful verdict; when
  disabled, timed out or unclassified the status disappears instead of showing “fallback”.
- **Normalized conversation schema**: turns store only `intent`; legacy `tab` fields are migrated on
  read, so history no longer depends on the removed tab concept.
- **Cheaper classification**: no request while the panel is collapsed; concurrent classification of
  the same sentence shares one request; changing endpoint/model/thresholds invalidates old verdicts.

### Fixes

- The automatic render-fix turn referenced the removed `retryCtx.tab`, losing its intent marker.
- Double-clicking Send during intent classification could fire the same sentence twice; Send is now
  locked during classification.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. Users on an older version
will be offered this release via **Help → Check for updates** (the update package is this same
installer; its signature is in `latest.json`).

> This installer is **not yet Authenticode-signed**, so Windows SmartScreen may show a warning.
