### 本次亮点

- **「解图」回复默认按 Markdown 预览显示**：标题、编号/项目符号列表、粗体、行内代码、引用、
  分割线、表格与链接都按排版显示，不再是满屏 `###`、`**` 和 `| --- |`。
- **每条回复可切换「预览 / 源码」**：切换到源码看模型输出的原始 Markdown，方便核对或拷走；
  切换只重画这一条，不会把长对话滚到底，其他回复保持各自的视图。
- **流式输出边写边渲染**：回复还在生成时就按当前视图实时更新，不用等整段结束。
- **视图状态跟着消息走**：切页签、切文档、整栏重排后仍停留在你选的视图；
  从磁盘恢复的历史「解图」轮次也默认按预览显示。
- **渲染是安全的**：模型输出一律当纯文本处理，不执行内联 HTML/脚本；`javascript:` 这类链接
  不会变成可点链接；图片只保留说明文字，预览不会因为一条回复去发网络请求。外部链接只在点击时
  交给系统浏览器打开。

### 修复

- **「解图」不再把 Markdown 标记原样显示**：上一版的只读解读返回的是 Markdown 文本，
  界面却按纯文本显示；现在默认渲染预览，需要原文时切「源码」即可。

# English

**Diagramon {{version}}** makes the Explain output actually readable as Markdown: preview by default, one click to the raw source.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Explain replies now render Markdown by default**: headings, ordered/bullet lists, bold, inline code,
  quotes, rules, tables and links are formatted instead of showing raw `###`, `**` and `| --- |`.
- **Per-reply Preview / Source toggle**: switch to Source to read or copy the model's original Markdown.
  The switch redraws only that reply, so a long conversation does not jump to the bottom.
- **Streaming renders as it arrives**: the reply updates in the selected view while it is still being
  generated — no need to wait for the end of the message.
- **The view sticks to the message**: switching tabs, documents or re-rendering keeps your choice, and
  Explain turns restored from disk also open in Preview.
- **Rendering is safe**: model output is treated as plain text, inline HTML/scripts are never executed,
  `javascript:` links are never clickable, and images keep only their alt text so a preview never makes
  a network request. External links are handed to the system browser only when clicked.

### Fixes

- **Explain no longer shows Markdown markers literally**: the previous release returned Markdown but
  displayed it as plain text; it now renders a preview by default, with the original one click away.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. Users on an older version
