### 本次亮点

- **Mermaid 架构图（`architecture-beta`）现在完整可用。** 用 `group` / `service` / `junction`
  和端口连线描述服务与资源关系，预览、分屏、SVG / PNG 导出都走同一条链路；内置图标
  （cloud / database / disk / internet / server）随包离线渲染，不需要联网。
- **大纲按架构图的语义显示。** 以前侧栏会把 `cloud` / `database` / `server` 这些**图标名**
  当成节点名；现在显示分组名、服务标签与真实连线（端口方向也保留），可以直接跳转。
- **AI 会画架构图了。** 提示词里补了 `architecture-beta` 的语法、内置图标与限制（不支持
  连线标签 / `classDef` / `style`）；模型不带代码围栏直接输出时也能正确识别。
- **不再显示对架构图无效的「布局」开关。** 架构图使用 Mermaid 自带的 fcose 力导向布局，
  顶栏/状态栏不再给出点了没反应的 elk / dagre 选项，副标题会说明布局是固定的。

### 修复

- 架构图渲染不再依赖“它会忽略顶层布局”这个上游细节：应用侧显式不传 `layout`。
- 架构图的语法校验保持零误报（括号配对规则不会把 `group id(icon)[label]` 当成错误）。
- 布局入口在泳道图 / 脑图 / 架构图三处统一隐藏，切换文档头部时按钮会立即跟着变。

# English

**Diagramon {{version}}** completes Mermaid architecture diagrams: render them, browse them in the
outline, and let the AI generate them.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Mermaid architecture diagrams (`architecture-beta`) are fully usable now.** Describe services and
  resources with `group` / `service` / `junction` and port-to-port edges; preview, split view and
  SVG / PNG export all use the same path. The built-in icons (cloud / database / disk / internet /
  server) render offline, no network needed.
- **The outline follows architecture semantics.** It used to list icon names (`cloud`, `database`,
  `server`) as node names; now it shows group titles, service labels and real edges (with port
  directions), all clickable.
- **The AI can draw them.** The prompt now teaches `architecture-beta` syntax, built-in icons and
  limits (no edge labels / `classDef` / `style`); bare output without a code fence is accepted too.
- **No more useless “Layout” switch.** Architecture diagrams use Mermaid's built-in fcose layout; the
  toolbar and status bar no longer offer elk / dagre switches that do nothing, and the subtitle says
  the layout is fixed.

### Fixes

- Rendering no longer relies on the upstream detail that architecture diagrams ignore the top-level
  `layout`: the app now simply does not pass one.
- Syntax validation stays free of false positives (`group id(icon)[label]` is not treated as an
  unbalanced bracket).
- The layout entry is now hidden consistently for swimlanes, mindmaps and architecture diagrams, and
  disappears immediately when the document header changes.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. Users on an older version
