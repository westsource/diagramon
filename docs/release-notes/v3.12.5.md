### 本次亮点

- **泳道图能画出来了**：源码用 `swimlane-beta LR`（或 `TB`）开头，顶层每个 `subgraph` 就是一条泳道，
  节点与连线的写法与 flowchart 完全一致。此前的预览会把泳道压成一张普通流程图 —— 节点还在，
  泳道框与泳道名全没了，现在按泳道图的布局渲染。
- **不再给你一个切不动的「布局」按钮**：泳道图的布局固定是 `swimlane`，预览顶栏只留「外观 / 配色」，
  副标题写明这一点；状态栏、命令面板、布局弹窗三处也都不再提供这个选项。
- **大纲按图类型说话**：同一份数据，泳道图的顶层分组叫「泳道」而不是「子图」。
- **转换**：泳道图可转 **DOT**（泳道 → cluster）与 **D2**（泳道 → 容器），Excalidraw 照常交给引擎；
  **drawio 方向明确不支持** —— 它随包的 Mermaid 导入器认不出 `swimlane-beta`，转换对话框会把这一格
  标成不可用并写清原因，而不是让你等一次引擎失败。
- **AI 会写泳道图**：你说「画一张按角色分道的泳道图」时，模型会得到 `swimlane-beta` 的语法与语义说明；
  它返回的整段泳道源码也能被正确识别为代码（此前会被当成一段散文丢掉）。
- **顺带修好了带 front matter 的 Mermaid**：`--- config: … ---` 与跨行的 `%%{init: …}%%`
  不再被当成图头部/语句 —— 这类文档现在能正常转 DOT / D2；`flowchart` 不带方向也按 TB 处理
  （Mermaid 自己接受这种写法，旧实现会报「缺方向」）。

### 修复

- **泳道图退化成普通流程图**：预览层把全局布局（默认 ELK）传给 Mermaid，覆盖了泳道图自己的
  `swimlane` 布局。现在泳道图文档不传全局布局，只钉住泳道布局。
- **带配置头的 Mermaid 转不出去**：转换器把 front matter 的 `---` 当成头部报错；多行
  `%%{init}%%` 的尾巴被当成一条语句。两处都已跳过。

# English

**Diagramon {{version}}** brings Mermaid 12's swimlane diagrams into editing, preview, outline, AI and conversion.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Swimlanes actually render now.** Start the source with `swimlane-beta LR` (or `TB`); every top-level
  `subgraph` is a lane, and nodes and edges keep exactly the flowchart syntax. The preview used to flatten
  them into an ordinary flowchart — nodes were there, the lane frames and lane titles were not.
- **No dead "Layout" button.** A swimlane diagram's layout is fixed to `swimlane`, so the preview top bar
  keeps only Look / Colours and the subtitle says so; the status bar, command palette and layout pop-up
  no longer offer it either.
- **Outline speaks the diagram's language**: the top-level groups of a swimlane document are called
  "lanes" rather than "subgraphs".
- **Conversion**: swimlane diagrams convert to **DOT** (lane → cluster) and **D2** (lane → container),
  and Excalidraw still goes through its engine; **drawio is explicitly unsupported** — the Mermaid
  importer bundled with drawio does not recognise `swimlane-beta`, so the dialog marks that target
  unavailable and says why instead of letting you wait for an engine failure.
- **The AI can write swimlanes**: ask for "a swimlane diagram split by team" and the model gets the
  `swimlane-beta` syntax and semantics; a returned swimlane source is now recognised as code
  (it used to be discarded as prose).
- **Fixed along the way: Mermaid with front matter.** `--- config: … ---` and multi-line `%%{init: …}%%`
  are no longer mistaken for the diagram header / a statement — such files now convert to DOT and D2;
  a `flowchart` header without a direction is treated as TB (Mermaid accepts it; the old code said
  "missing direction").

### Fixes

- **Swimlanes degraded to a plain flowchart**: the preview passed the global layout (ELK by default) to
  Mermaid, overriding the diagram's own `swimlane` layout. Swimlane documents now skip the global layout
  and pin the swimlane one.
- **Mermaid with a config header could not be converted**: the converter treated the front matter's `---`
  as the header and the tail of a multi-line `%%{init}%%` as a statement. Both are skipped now.
