### 本次亮点

- **产物 + 落点**：AI 输入框上方多了一行段控 —— 产物（Mermaid / DOT / D2）与落点（留在编辑器 / 转成画布）。选择按文档记住；落点选“转成画布”时，这一轮结束会自动落到 drawio。
- **结果卡双动作**：除了「应用到编辑器」，还能「转成 drawio 继续编辑」；DOT 产物走 Graphviz 布局，Mermaid / D2 走各自的引擎，几何都保留。
- **AI 落地会归一化**：画布产物的 id 加稳定前缀（`mm-`），后续元素级操作能回指；转换记录里如实写「已归一化」与保真度。
- **转换失败能修一次**：转换不完整时，卡片直接给出原因（通常带行号），点「让 AI 修」只重试一次；不会无限循环烧钱。

### 修复

- **Mermaid → drawio 不再干等 18 秒，也不会偶尔只拿到半张图**：等待改成“连续两次相同才算完成”，上限 8 秒；超时按失败处理并回滚空标签页。
- **画布产物的结构计数与报告一致**：归一化前后都会先自检（节点/边/容器），数不出来就不产出文件。

# English

**Diagramon {{version}}** connects “the AI drew it” with “keep editing” in one step: pick an artifact and a landing, and the result lands on the canvas; incomplete conversions no longer leave you staring at an empty canvas.

### Downloads

| Option | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Supports **built-in auto-update**; fetches the WebView2 runtime if missing |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

Portable notes: the ZIP contains `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\` — they
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs nothing extra installed: no Node.js, no Chrome, no VC++ redistributable (the exe links the
CRT statically); only the WebView2 runtime that ships with Windows 10/11. “Check for updates” still
finds new releases, but applying one downloads the **installer** (it does not replace the portable
folder in place) — to stay portable, download the new ZIP and overwrite.

### Highlights

- **Artifact + landing** — a new segmented row above the AI input: artifact (Mermaid / DOT / D2) and
  landing (keep in editor / to canvas). The choice is remembered per document; with “to canvas” the
  finished turn lands on drawio automatically.
- **Two actions on the result card** — besides “Apply to editor”, “Convert to drawio and keep editing”;
  DOT goes through Graphviz layout, Mermaid / D2 through their own engines, geometry preserved.
- **AI landings are normalized** — canvas output gets stable id prefixes (`mm-`) so later element-level
  actions can point back; the conversion record says “normalized” and reports fidelity honestly.
- **A failed conversion can be fixed once** — the card states the reason (usually with a line number);
  “Ask AI to fix” retries exactly once, no runaway spend.

### Fixes

- **Mermaid → drawio no longer waits 18 seconds or occasionally grabs half a diagram** — waiting is now
  “two identical reads in a row”, capped at 8 seconds; a timeout is a failure and the empty tab is rolled back.
- **Canvas output counts match the report** — normalized output is self-checked (nodes / edges /
  containers) before it is written; a mismatch is an error, not a half-broken file.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid / Graphviz DOT / drawio /
Excalidraw, all editable with live preview, plus AI for generation, review and image recognition.
Rendering and validation work offline — only the AI features you explicitly use send code or images
to the upstream you choose.

Website: <https://www.diagramon.com>

- Windows 10 / 11 64-bit
- WebView2 runtime (usually preinstalled; the installer fetches it when missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all ship with the app
