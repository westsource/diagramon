### 本次亮点

- **「格式化源码」真的会格式化**：Mermaid / DOT 统一缩进、清行尾与连续空行；再点一次会明确说「无需改动」，不会再无条件报“已完成”。D2 只做空白规整，不重排边。
- **D2 → drawio 走统一管线**：与 DOT 一样先落到 `CanvasPlan`，再由 Rust 生成 mxfile；产物使用稳定前缀 id（`d2-`），转换记录里有几何/样式保真度与逐条说明。
- **转换记录可操作**：在画布打开、重转、复制报告。重转会先核对源文本 hash，源改过会先问你（会新建标签页，不覆盖你手改的产物）。

### 修复

- **格式化不再只删行尾空格却报成功**（G22）：改动处数由 Rust 返回，`0` 就是“无需改动”。
- **D2 的形状退化/主题/多板不再只写在一条 notes 里**：逐项进报告；多板目前按「合并为单页」如实记录，不硬拆。
- **转换记录不再只有一行文本**：可以展开看报告、直接跳到目标画布或重转。

# English

**Diagramon {{version}}** fixes a button that had been “pretending to succeed”, and brings the D2
delivery chain onto the same pipeline: formatting really changes the file, and D2 output gets stable
ids plus a report you can check.

### Downloads

| Option | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Supports **built-in auto-update**; fetches the WebView2 runtime if missing |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

Portable notes: the ZIP contains `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\` — they
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs nothing extra installed: no Node.js, no Chrome, no VC++ redistributable (the exe links the
CRT statically); only the WebView2 runtime that ships with Windows 10/11. “Check for updates” still
finds new releases, but applying one downloads the **installer** (it does not replace the portable
folder in place) — to stay portable, download the new ZIP and overwrite.

### Highlights

- **“Format source” now really formats** — Mermaid / DOT get consistent indentation and no trailing
  whitespace or repeated blank lines; running it again says “Nothing to change” instead of claiming
  success unconditionally. D2 only touches whitespace and never reorders edges.
- **D2 → drawio goes through the shared pipeline** — like DOT, it lands on `CanvasPlan` first and Rust
  emits the mxfile; output uses stable prefixed ids (`d2-`), and the conversion record reports
  geometry/style fidelity plus every degradation.
- **Conversion records are actionable** — open on canvas, re-convert, copy report. Re-convert checks
  the source hash first and asks when the source changed (it opens a new tab, so hand edits are never
  overwritten).

### Fixes

- **Formatting no longer just trims trailing spaces and reports success** (G22): the change count comes
  from Rust, and `0` means “nothing to change”.
- **D2 shape fallbacks / theme / boards are no longer a single note** — they become individual report
  items; multiple boards are currently recorded as “collapsed into one page” rather than guessed apart.
- **Conversion records are no longer one line of text** — expand the report, jump to the target canvas,
  or re-convert.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid / Graphviz DOT / drawio /
Excalidraw, all editable with live preview, plus AI for generation, review and image recognition.
Rendering and validation work offline — only the AI features you explicitly use send code or images
to the upstream you choose.

Website: <https://www.diagramon.com>

- WebView2 runtime (usually preinstalled; the installer fetches it when missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all ship with the app

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and install. Existing users get this
