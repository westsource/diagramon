### 本次变化

- **搜索并入资源管理器**。资源管理器顶部常驻内容搜索框：输入非空时结果替换文件树，清空后回到文件树；
  正则、大小写、去抖、停止与结果跳转保持不变。活动栏不再有独立搜索图标。
  `Alt+2` / `Ctrl+Shift+H` 直接聚焦这个搜索框。
- **转换只保留一个执行入口**。移除活动栏与侧栏的「转换中心」，也移除文件菜单、状态栏和标签菜单里的重复入口；
  执行转换统一走标签条右侧的「转换」按钮（`Alt+Shift+C` 仍可用）。状态栏的格式项改为只读指示。
- **转换能力说明收进帮助**。新增「帮助 → 转换能力一览…」只读窗口，合并原侧栏矩阵与设置页
  「格式与转换」的格式注册表、全部方向、可用性与原因；不提供操作按钮。
- **设置窗口移除「格式与转换」页**。该页本来就是只读的，内容已并入上面的帮助说明。
- **AI 标签区补分割线**。对话生成 / 识图 / 改图 与下方消息区之间增加 1px 分割线，与源码/渲染标签条观感一致。

# English

**Diagramon {{version}}** is a UI consolidation release: search no longer has its own sidebar view,
conversion keeps a single action entry in the tab bar, and the capability reference now lives in Help.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still works in the portable build, but updates are delivered as the **installer**
(it never patches the portable folder in place) — download the new ZIP to keep using it.

### Changes

- **Search is now part of Explorer.** A content search field is always available at the top of Explorer:
  a non-empty query replaces the file tree with grouped results, and clearing it restores the tree.
  Regex, case sensitivity, debounce, stop and result navigation are unchanged. The separate search
  activity icon is gone; `Alt+2` / `Ctrl+Shift+H` focus the field directly.
- **One conversion entry.** The activity-bar and sidebar conversion centers are removed, along with
  duplicate entries in the File menu, status bar and tab menu. Conversion runs from the tab bar's
  **Convert** button (`Alt+Shift+C` still works). The status-bar format item is now read-only.
- **Conversion reference moved to Help.** A new read-only **Help → Conversion reference…** dialog
  combines the old sidebar matrix and the settings “Formats & Conversion” page: format registry,
  every direction, availability and reasons. It has no action buttons.
- **Settings no longer has a “Formats & Conversion” tab.** That page was read-only; its content now
  lives in the Help reference.
- **AI tab divider.** A 1px divider now separates Generate / Vision / Review from the message stream,
  matching the source/preview tab bar.

### Fixes

- Persisted `sidebar_view = search / convert` values are migrated to Explorer on upgrade, so the
  sidebar no longer comes up blank.
- Removed duplicate conversion entries and the mixed “reference vs. action center” responsibility.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. Users on an older version
will be offered this release via **Help → Check for updates** (the update package is this same
installer; its signature is in `latest.json`).

> This installer is **not yet Authenticode-signed**, so Windows SmartScreen may show a warning.
