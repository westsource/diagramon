### 修复

- **AI 不再主动改写你自己编辑的正文**：渲染失败时的自动修正（AI 设置 →「渲染失败时让 AI 修一次」）
  原先只看"上一次是不是 AI 落的版本"，于是 —— AI 落一版之后你接着手写，只要写出语法错，
  自动修正就会把你正在编辑的正文整块覆盖掉。现在多一道判断：**出错时正文必须还是 AI 刚落的那一版**
  才修。你手改出来的错误照常报在预览、状态栏与问题面板里，修不修由你决定（「改图」页签一句话就能让它改）
- **源码窗口的搜索/替换面板不再盖住菜单**：CodeMirror 给面板自带的层级是"整页最上层"的量级
  （比弹出菜单与模态遮罩都高），于是开着搜索框点菜单，菜单被面板压住看不见。现在编辑器内部
  的面板与提示都收在编辑器自己的层里，菜单/对话框/提示条始终在它上面

### 说明

- 自动修正的其余约定不变：仍受设置开关控制、**每轮最多一次**（防死循环）、只在当前这份文档上生效，
  而且它是**真实计费**的一次调用
- 画布型（drawio / Excalidraw）不受这次改动影响 —— 它们的浮层在自己的承载页里，天然隔离

# English

**Diagramon {{version}}** is a "don't act on its own" patch: the AI's render-failure auto-fix no longer
touches **your** edits, and the source window's search/replace panel no longer floats above the menus.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Fixes

- **The AI no longer rewrites documents you edited yourself** — the render-failure auto-fix
  (AI settings → "let the AI fix a failed render once") used to look only at "was the last applied
  version the AI's?", so after an AI apply your own typing could be overwritten wholesale the moment
  it introduced a syntax error. There is now one more condition: **the body must still be exactly the
  version the AI applied**. Errors you type yourself are still reported in the preview, status bar and
  problems panel — fixing them stays your call (one line in the "Review" tab asks the AI to)
- **The source window's search/replace panel no longer covers the menus** — CodeMirror ships that panel
  with a "top of the page" z-index (above both the popup menus and the modal scrim), so opening a menu
  with the search box visible left the menu hidden behind it. The editor's own panels and tooltips are
  now contained in the editor's own layer, and menus/dialogs/toasts always sit above them

### Notes

- The rest of the auto-fix contract is unchanged: it obeys the setting, runs **at most once per round**
  (loop protection), only for the current document, and it is a **billed** call
- Canvas formats (drawio / Excalidraw) are unaffected — their floating UI lives inside their own host
  page and is isolated by the iframe

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. Users on an older version
will be offered this release via **Help → Check for updates** (the update package is this same
installer; its signature is in `latest.json`).

> This installer is **not yet Authenticode-signed**, so Windows SmartScreen may show a warning.
