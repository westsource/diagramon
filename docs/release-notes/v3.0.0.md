# English

**Diagramon 3.0.0** is the **first public release of dev3.0**: the desktop client was rebuilt from
scratch against the UI prototypes, on **Rust + Tauri 2 + the system WebView**.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_3.0.0_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-3.0.0-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **All four formats edit and preview live**: Mermaid, Graphviz DOT, drawio and Excalidraw.
  Rendering, syntax checking and format conversion **all happen on your machine** — bundled engines
  (WASM / packaged JS) plus canvas runtimes shipped inside the installer.
  **No subprocess is ever spawned and no external request is ever made.**
- **The canvas *is* the editor**: edits in drawio / Excalidraw are written back into the document body
  automatically, while what lands on disk stays a diffable mxfile XML / scene JSON file that reuses the
  same save, save-as and recent-files path.
- **Format conversion**: Mermaid → DOT (pure Rust), Mermaid → drawio / Excalidraw (handed to each
  engine's own parser). One-way, opened in a new tab, original untouched; **lossy conversions list
  exactly what did not migrate**, and unavailable directions are still shown with a stated reason.
- **Workspace**: open a folder and browse the tree, **search the whole workspace**, file watching with a
  conflict banner for external changes, single instance with file associations, autosave and crash recovery.
- **AI is a first-class citizen**: three tabs for generate / image recognition / review; vision can
  **capture a region of the screen** (multi-monitor and DPI scaling never come into play); BYOK
  (OpenAI-compatible / Ollama / custom) and the **membership cloud gateway** are shown as separate
  groups; usage counts only tokens the provider actually reports — anything unreported shows `—`, never `0`.
- **Cloud**: login tokens live in the OS credential store (Windows DPAPI) and never reach the front end;
  **silent token refresh** (an expired access token is renewed automatically, so a restart no longer asks
  you to sign in again); the account view shows AI entitlement and credit balance; cloud documents come
  with a folder tree and a save-to-cloud dialog that lets you pick a target folder.
- **Built-in auto-update** (minisign signature verification), **light and dark themes**, multiple accents,
  panel state and recent files restored on restart, and a bilingual (zh-CN / en-US) interface.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer
