### 本次亮点

- **思考过程会存下来了**：3.5.3 让推理块可以折叠 / 展开，但它只活在内存里 —— 重启后那一轮连块都没有，
  「随时点开重读」成了空话。现在推理**随会话一起落盘**，重启后展开读到的还是同一份原文。
  连带一处更要紧的：**只有思考、没有正文**的那一轮（思考型模型把整轮预算花在推理上）现在也会存 ——
  推理是那一轮唯一的产出，以前它整轮都不入库。
- **欢迎页「最近」+「更多」**：默认页的最近列表固定列 5 条，旁边的「更多」打开**文件打开历史**窗口：
  按打开时间倒序（本机最多留 50 条，之前是 10 条），可按文件名或路径过滤，**点一行即打开**
  （已在标签页里的会切过去）。
- **顺手修掉一个张冠李戴的入口**：文件菜单「最近打开文件 → 更多…（含搜索过滤）」与 `Ctrl+R` 以前打开的是
  **AI 会话历史**，与"最近文件"四个字对不上 —— 现在它们打开的是上面那个文件打开历史窗口。
- **预览顶栏的「适应视图」按钮去掉了**：它与画布浮动工具里的那颗完全重复。适应视图本身没动 ——
  双击画布、`Ctrl+0`、视图菜单与命令面板都还在。

### 修复

- 「历史会话」对话框里那种轮次以前会显示成一条空白记录，现在如实写明「本轮没有正文，只有 N 字思考过程」。
- 旧版本的会话文件（没有思考字段）照样能读出来，升级不会让历史会话变空。

# English

**Diagramon {{version}}** clears up three long-standing rough edges: the AI's reasoning no longer dies with
the run, the preview top bar loses a redundant "Fit to view" button, and the welcome page's "Recent" list
finally has a **More…** that opens file-open history instead of AI conversation history.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **The reasoning is stored now.** 3.5.3 made the thinking block collapsible, but the text only lived in
  memory — after a restart that turn had no block at all, so "open it again whenever you like" was an
  empty promise. The reasoning is now **persisted with the conversation**, so expanding it after a
  restart shows the same text. More importantly, a turn that produced **no answer text** (a reasoning
  model spending its whole budget thinking) is now stored too — that reasoning is the turn's only output
  and it used to be dropped entirely.
- **Welcome page "Recent" + "More…".** The default page lists 5 recent files, and its **More…** button
  opens the **file open history** window: newest first, up to 50 entries kept locally (it used to be 10),
  filterable by file name or path, and **clicking a row opens that file** (a file already in a tab is
  focused instead).
- **A mis-wired entry point fixed.** **File → Open recent → More… (with search)** and `Ctrl+R` used to
  open **AI conversation history** — nothing to do with recent files. They now open the file open
  history window above.
- **The preview top bar's "Fit to view" button is gone** — it duplicated the one in the canvas floating
  toolbar. Fit itself is untouched: double-click the canvas, `Ctrl+0`, the View menu and the command
  palette all still work.

### Fixes

- Such a turn used to show up as a blank row in the Conversation history dialog; it now says
  "(no answer text this turn — N chars of reasoning only)".
- Conversation files written by older versions (without the thinking field) still load — upgrading never
  empties your history.
