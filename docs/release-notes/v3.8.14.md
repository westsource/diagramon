### 本次亮点

- **带分组的图转 Excalidraw 终于能编辑了**：以前凡是图里用了 `subgraph`（分组框），转成 Excalidraw 后
  整张图会变成一张**静态图片** —— 看着对，但每个框、每条线都拖不动。现在会还原成真正的图形元素，
  可以继续编辑。实测一份 148 行的部署图：修前 1 个图片元素，修后 181 个可编辑元素
  （59 个框 + 34 条箭头 + 88 段文字）。
- **内联类名不再让整份文件转不出来**：Mermaid 允许把样式类直接写在节点上（`A[文本]:::某类`），
  这种写法以前会让转 DOT / D2 直接报「第 N 行：语句尾部有没解析完的内容」而整份失败。
  现在照常识别，样式也一并迁移过去。

### 修复

- **`:::类名` 内联类名导致 Mermaid → DOT / D2 失败**：解析器只认 `id[标签]`，不认节点后缀的
  `:::类名`，于是把 `:::类名` 当成语句尾部的多余内容整份报错。现在两种写法等价处理：
  遇到 `:::` 会读出类名（支持 `:::a,b` 多个），与单独的 `class A 类名` 语句效果一致；
  类名对应的样式会迁移到目标格式（DOT 全挂上；D2 的 `.class` 只能挂一个，多类时取第一个并在
  转换记录里如实说明）。
- **带 `subgraph` 的 Mermaid → Excalidraw 退化成位图**：上游转换器用**裸 id** 去文档里找分组元素，
  而实际渲染出来的 id 带有一段每次都会变的序号前缀，于是必然找不到、抛错后被兜底成整张图片。
  现在转换期间会按 id 后缀再找一次，分组能正确还原；转换结束立刻撤掉这层兜底，不影响其它操作。

# English

**Diagramon {{version}}** fixes two conversion defects: Mermaid files that assign style classes inline now convert to DOT / D2, and diagrams with `subgraph` blocks no longer collapse into a single non-editable image when converted to Excalidraw.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Diagrams with groups are finally editable in Excalidraw**: any diagram using `subgraph` blocks used to
  convert into a single **static image** — it looked right, but nothing could be dragged. It now comes
  through as real shapes. Measured on a 148-line deployment diagram: 1 image element before,
  181 editable elements after (59 boxes + 34 arrows + 88 text runs).
- **Inline style classes no longer break a whole file**: Mermaid lets you attach a class right on a node
  (`A[text]:::someClass`). That used to make Mermaid → DOT / D2 fail outright with
  "trailing unparsed content on line N". It is now understood, and the styling comes across too.

### Fixes

- **`:::class` inline class made Mermaid → DOT / D2 fail**: the parser only understood `id[label]` and
  treated the trailing `:::class` as leftover text, failing the whole file. Both spellings are now
  equivalent: `:::` is read (including `:::a,b` for several classes) and behaves exactly like a separate
  `class A someClass` statement. The styling is migrated (DOT gets all of them; D2's `.class` holds one,
  so the first is used and the conversion record says so).
- **Mermaid → Excalidraw with `subgraph` degraded to a bitmap**: the upstream converter looked up the
  group element by its **bare id**, while the rendered id carries a per-render numeric prefix — so the
  lookup always missed, threw, and was caught into a whole-diagram image fallback. Conversion now retries
  the lookup by id suffix, so groups come through correctly; the fallback is removed as soon as the
  conversion finishes and does not affect anything else.

### Notes

- The Excalidraw bundle and its Mermaid converter were bumped together (`mermaid-to-excalidraw` 2.3.0).
- Two canvas probes gained an opt-in flag for restricted sessions (`DGM_PROBE_NO_SANDBOX=1`).
  Development and acceptance tooling only — the product itself is unaffected.
