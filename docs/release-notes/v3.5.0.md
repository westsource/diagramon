### 本次亮点

- **新增 D2 格式（`.d2`）**：D2 是新一代文本图表语言，容器可以嵌套、形状与类样式用属性表达。
  它跟 Mermaid / DOT 一样是文本型 —— 三态视图、滚轮缩放平移、导出图片、大纲、查找替换、
  AI 直接生成 D2 代码，全部继承；渲染用 D2 官方的 wasm 构建（随包 11MB），**不联网、不起子进程**。
- **三种布局引擎随手切**：`dagre`（默认，最快）、`elk`、`tala`（较慢，按需选）——
  状态栏的布局项与「布局引擎」菜单都能切，切完按新布局重新渲染。
- **首次打开 `.d2` 会等几秒**：D2 的引擎有 11MB 的 wasm 要先解压实例化，界面会明说
  「正在初始化 D2 引擎」，之后每次渲染只要几十毫秒。为了不让你白等，**只有你最近开过 `.d2`
  时才会在启动后台预热** —— 不用 D2 的人不会为此多背一百多兆常驻内存。
- **Mermaid → D2**：flowchart 的形状（判定 / 圆角 / 体育场 / 子程序 / 圆柱 / 圆 / 六边形…）、
  `subgraph` → D2 容器（容器内的方向也保留）、`classDef` → `classes`、虚线 / 加粗 → 样式属性，
  `%%` 注释改写成 D2 的 `#` 注释。哪一类信息没迁移过去，转换记录里逐条写明，不静默丢。
- **DOT → D2**：节点 / 边 / 属性 / `subgraph`（按 label 命名）/ 注释 / `rankdir` 都能转；
  DOT 的版式约束（`rank` / `pos` / 端口 / `record`…）在 D2 里没有对应物，**版式会重新计算**，
  这一点在转换记录里明说。
- **D2 → drawio（保几何）**：这是「从 D2 出去」的出口。用 D2 自己的编译器先算出**绝对几何**，
  再映射成 mxGraph —— 节点位置与连线走线**原样保留**，转出来是一份普通 drawio 文档，
  可以接着拖拽、改字。主题 / 手绘风 / 图标 / 多板这类没有对应物的东西会在记录里说明降级。
- **报错带行列号**：D2 的语法错会显示成「第 N 行：……」，并且照旧把报错原文回喂给 AI 自动修一次。

# English

**Diagramon {{version}}** adds a fifth format, **D2**: another text-based diagram language with the
same source / split / preview triple, the same zoom-pan, PNG/SVG export, outline, find & replace and
AI generation as Mermaid and DOT — rendered by the official wasm build shipped with the app, **fully
offline**. Three conversion directions open up as well: `Mermaid → D2`, `DOT → D2` and
`D2 → drawio` (geometry preserved).

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **New format: D2 (`.d2`)** — a modern text diagram language where containers nest and shapes/classes
  are expressed as attributes. It is a text format like Mermaid/DOT, so the three view modes, wheel
  zoom and pan, image export, outline, find & replace and AI generation all carry over; rendering uses
  D2's official wasm build (11 MB, bundled) with **no network access and no subprocess**.
- **Three layout engines, switchable on the fly** — `dagre` (default, fastest), `elk` and `tala`
  (slower; pick it deliberately). Switch from the status bar or the "Layout engine" menu and the
  diagram re-renders for that layout.
- **The first `.d2` document takes a few seconds** — the engine inflates and instantiates 11 MB of
  wasm; the UI says "initializing the D2 engine", after which each render takes tens of milliseconds.
  So you don't wait needlessly, warm-up only happens **if you recently opened a `.d2` file** — people
  who don't use D2 never carry that 100 MB+ of resident memory.
- **Mermaid → D2** — flowchart shapes (decision / rounded / stadium / subroutine / cylinder / circle /
  hexagon…), `subgraph` → D2 container (with its inner direction kept), `classDef` → `classes`,
  dotted/thick lines → style attributes, and `%%` comments rewritten as D2 `#` comments. Whatever does
  not migrate is listed line by line in the conversion record — nothing is dropped silently.
- **DOT → D2** — nodes, edges, attributes, `subgraph` (named from its label), comments and `rankdir`
  all convert; DOT's layout constraints (`rank` / `pos` / ports / `record`…) have no counterpart in D2,
  so **the layout is recomputed**, which the conversion record states outright.
- **D2 → drawio (geometry preserved)** — the way out of D2. D2's own compiler produces **absolute
  geometry**, which is mapped onto mxGraph: node positions and edge routes are kept exactly, and the
  result is an ordinary drawio document you can keep dragging and editing. Theme / sketch / icons /
  multi-board are stated as degradations in the record.
- **Errors carry line numbers** — D2 syntax errors surface as "line N: …" and the raw error is still
  fed back to the AI for one automatic fix attempt.

### Fixes and notes

- The Conversion Center now explains unsupported directions more clearly: D2 is a superset of
  Mermaid / DOT (containers, `classes`, `vars`, `layers`…), so folding it back would mean deciding per
  feature what to drop — **D2 → Mermaid / DOT is deliberately not built**; the "get out of D2" need is
  served by `D2 → drawio` (geometry preserved, still editable).
- The installer grows by about 11 MB (the D2 wasm runtime ships inside it — still zero external
  requests).
