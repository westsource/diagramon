### 修复

- **AI 不再"花了 token 却没有输出"**：思考型模型（GLM / DeepSeek / Qwen 这一族）会把整段推理
  逐帧推进来（实测某轮 104 帧**全是**推理、一个正文字符都没有），而旧版客户端只认正文 ——
  推理被整包丢掉，界面上只剩一个空气泡，用量却照记。现在**思考过程实时显示**（"正在思考…（N 字）"
  + 原文），真的没有正文时会明确说清原因（含思考 token 数）并把推理留在那里给人读，
  回复落在别的页签也会记未读角标。
- **登录状态会保留了**：以前每次生成设备标识时字段名写错，设备标识**从未落盘** ——
  访问令牌一过期（30 分钟）就没法续期，于是"昨天登录过，今天打开还要再登一次"。
  现在登录后重启应用会直接是登录态。
- **BYOK（自带密钥）终于可用**：设置里填的密钥以前存到了读取端不认的位置 ——
  永远显示"未配置"、一调用就报「缺少 API Key」。现在写/读用同一把键，删模型也会顺手清掉密钥。
- **drawio 画布的两块浮动面板不再乱飘**：Shapes / Format 现在固定在画布顶栏**下方**，
  Format 的右缘与右下角缩放条对齐；画布变矮时也不会戳出底边（面板内容自己滚）。
- **顶栏里 drawio 自己的缩放按钮组已隐藏**：缩放/适应由本应用右下角的缩放条与
  `Ctrl+0 / Ctrl+= / Ctrl+-` 负责，画布内不再有第二份入口（Alt+滚轮照旧可用）。
- **标题栏不再显示文件全路径**：只留文件名（完整路径鼠标悬停在标签页头上就能看到）。

# English

**Diagramon {{version}}** is mostly a bug-fix release: AI turns that burned tokens and printed nothing,
**login that did not survive a restart**, and drawio's floating panels drifting around the canvas.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Fixes

- **AI no longer burns tokens and prints nothing.** Reasoning models (the GLM / DeepSeek / Qwen family)
  stream their whole chain of thought frame by frame — one measured turn was 104 frames of *pure*
  reasoning and not a single character of answer text — and the old client only understood answer text:
  all of it was dropped, leaving an empty bubble while usage was still billed. The thinking is now
  shown live ("Thinking… (N chars)" plus the transcript), a turn that really produced no answer says so
  explicitly (with the reasoning token count) and keeps the reasoning readable, and a reply that lands
  in another tab now raises an unread badge.
- **Login is remembered.** The device identifier was written with a mis-cased field name, so it was
  **never persisted** — once the 30-minute access token expired the session could not be refreshed,
  hence "I logged in yesterday and it asks me again today". Restarting now restores the signed-in state.
- **BYOK works at all.** Keys typed into settings used to be stored where the reader never looks —
  the model stayed "not configured" and every call failed with "missing API key". Both sides now use the
  same key, and deleting a model drops its secret.
- **drawio's floating panels stay put.** Shapes and Format are pinned below the canvas top bar, with the
  Format panel's right edge aligned to the zoom strip at the bottom-right; on shorter windows they no
  longer run past the bottom edge (the panel body scrolls instead).
- **drawio's own zoom button group in the top bar is hidden** — zoom/fit live in this app's zoom strip
  and in `Ctrl+0 / Ctrl+= / Ctrl+-`; there is no second set of controls inside the canvas
  (Alt+wheel still works).
- **The title bar no longer shows the full file path** — just the file name (hover the tab header to see
  the path).
