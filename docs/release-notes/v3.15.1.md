# 中文

必须能被将要编进 exe 的公钥验证，否则发布直接中止。

# English

**Diagramon {{version}}** fixes auto-update in 3.14.5 and 3.15.0: those builds shipped an update public key
with a single corrupted character, so every "Check for updates" ended in `The signature verification failed`.

### What was wrong

Update packages have always been signed with the correct private key; what was broken was the **public key
inside the client**. The 3.14.5 release (the first Linux build) introduced a one-character typo while editing
`tauri.conf.json`, so 3.14.5 / 3.15.0 clients compared correct signatures against a wrong key and always failed.
This release restores the key that matches the private key and adds a hard gate to the release pipeline:
signed artifacts must verify against the key that will be compiled into the exe, or the release aborts.

### ⚠️ What you need to do

| Your current version | How to get {{version}} |
|---|---|
| **3.14.5 or 3.15.0** (Windows / Linux) | Auto-update **cannot fix itself** (the wrong key is compiled in). Download and install this version manually once; updates work again afterwards |
| **3.14.4 or older** | "Help → Check for updates" works as usual (their key is correct) |
| New users | Just download and install this version |

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (Windows, recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (Windows, no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |
| **Linux AppImage** (no install) | [Download AppImage]({{appimage_url}}) (~{{appimage_size_mb}} MB) | `chmod +x` and run; **in-app auto-update supported** |
| **Linux deb** (Debian / Ubuntu) | [Download deb]({{deb_url}}) (~{{deb_size_mb}} MB) | Install with your package manager; needs WebKitGTK 4.1; **no** in-app auto-update (download the new version) |

Windows portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable — only the system
WebView2 runtime that comes with Windows 10/11.

### Highlights

- **Auto-update restored**: the update key and signatures are paired again; the release script now refuses to publish unless the signature verifies against the key embedded in the exe, so this class of bug cannot ship again.
- **Continues 3.15.0**: read-only share links (carrying the author's layout and Mermaid appearance), share pages rendered the author's way, "Use the online version" signing in with the desktop session, and the Convert/Share buttons on the tab strip swapped.
- **Cloud documents in "Recent"**: cloud entries are de-duplicated by `cloud_id` across the welcome page, File menu, sidebar and open-history window; network errors or expired sessions no longer drop history.
