**Diagramon {{version}}** 把配色从"看不见的视图状态"变成"看得见的源码内容"。

便携版说明：包里是 `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`，**必须放在一起**
（`ui\` 与 `assets\` 是从磁盘读的，不在 exe 里）。它**不依赖额外要装的东西**：不需要 Node.js、

### 本次亮点

- **选配色 = 改正文**：在预览顶栏选一个色系，配色块立刻写进源码（`%% dgm-palette:…`），
  源码窗口和渲染看到的是同一份东西。**落不落盘由「设置 → 编辑器 → 自动保存」决定**，
  以前那条"颜色只是预览、要再点一次写入正文"的分叉没有了。
- **带得走**：别的工具（mermaid live、GitHub、编辑器插件）打开这份源码就有颜色，
  不再依赖本应用的记录。
- **未保存的文档也记得住**：配色不再是按文件路径记的外挂状态，新建文档选完就是它自己的内容。
- 打开文件**不会变脏**：按图内容推测的配色只作为建议提示，选了你才写进正文。
- 老文件迁移：以前记过色系但正文里还没有配色块的，首次打开时会把块补进缓冲区（不自动落盘，可撤销）。
- AI 应用结果、格式转换之后会自动按同一色系补回配色块，不会出现"应用完颜色没了"。

### 修复

- **「行底色」按钮看不出开关状态**：按钮一直在切设置，但缺少按下态样式，点完只有 title 变了。
  现在关闭时是普通描边，打开时是强调色底 + 描边，并带 `aria-pressed`。
- **配色菜单少了一条分隔线**：「无」和「按当前主题重排配色 / 让 AI 挑」挤在一起，
  看不出是"选择"与"动作"两类。

### 注意事项

- **切主题不会自动改色**：配色块是选色系那一刻按当时明暗主题算出来的快照（块头会写「亮色」或「暗色」）。
  换主题后想重算，用配色菜单里新增的「按当前主题重排配色」。
- **「设置 → 默认配色」现在只作用于新建文档**；已有文件各自在预览顶栏选，选完即写进它的正文。
- 升级后，之前只"跟随默认"而没有真正选过的文件会显示为无色，选一次即可（之后颜色会固定在文件里）。

# English

**Diagramon {{version}}** turns palette colors from an invisible view state into visible source text.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Picking a palette edits the source**: choosing a scheme in the preview toolbar writes the palette
  block into the source immediately, so the editor and the render show the same thing.
  **Saving follows your auto-save setting** — the old "colors are preview-only, bake them later" split is gone.
- **Portable colors**: mermaid live, GitHub rendering and editor plugins show the colors directly.
- **Unsaved documents remember too**: the choice is no longer sidecar state keyed by file path.
- Opening a file **never dirties it**: the palette guessed from the diagram is only a suggestion.
- Migration: documents that had a remembered scheme but no block get one written into the buffer on first open
  (unsaved, undoable).
- After AI apply or a format conversion the palette block is restored automatically, so colors never vanish.

### Fixes

- **The row-tint button gave no state feedback**: it toggled the setting but had no pressed style.
  It now shows an accent background when on, with `aria-pressed` for accessibility.
- **Missing separator** in the palette menu between the scheme list (including "None") and the actions.

### Notes

- **Switching theme does not recolor**: the block is a snapshot for the theme active when you picked it
  (its header says light or dark). Use the new "Regenerate for current theme" action after switching.
- **"Default palette" in settings now only applies to new documents**; existing files pick their own.
- Documents that only ever "followed the default" will show no colors after upgrading — pick a scheme once
  and it becomes part of the file.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. Users on an older version
will be offered this release via **Help → Check for updates** (the update package is this same
installer; its signature is in `latest.json`).

> This installer is **not yet Authenticode-signed**, so Windows SmartScreen may show a warning.
