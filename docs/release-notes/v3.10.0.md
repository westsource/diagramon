### 本次亮点

- **Explain：只读解释当前图表**。空态里的「解释当前这张图」现在走独立的 `Explain` 意图：
  只输出业务定性、主链路、模块边界、异常分支与风险，**不输出代码围栏、不提供“应用”按钮**，
  不会再把解释变成一次覆盖文档的生成。
- **识图支持 Ctrl+V 与拖拽，一次可放两张图对比**。截图后直接在识图弹窗粘贴；文件可以拖进去；
  最多两张，顺序就是上行顺序。弹窗显示已选数量，聊天区两张缩略图都会保留。
  图片仍然只在内存里，不落盘、不进会话记录。
- **单条消息可重试 / 编辑后重发 / 删除**。不用为了改一句提示词清空整段对话；
  “重新生成”会记录服务端账本行，下一次请求带上 `Retry-Of` 归因。
- **有图时打开 AI 面板自动落到「改图」**。源码区的「让 AI 改这段」也走「改图」，
  不再先跳到「对话生成」再让用户自己切页签；用户显式点过的页签仍然尊重。
- **云网关新增 `auto` 档位**：模型下拉里可直接选「自动选档」，由服务端按能力和图片输入需求路由。
- **网关归因头接通**：`scene` 与 `retry_of` 会随网关请求发送，BYOK 请求不会带这些内部元数据。
- **转换记录更可读**：AI 增强转换单独标记，成功 / 提前止损 / 回退本地 / 取消 / 失败分别显示；
  有目标文档的记录可以点开。

### 修复

- 识图弹窗只保留一张图、第二张粘贴后覆盖第一张的问题。

- 单条消息操作缺少可访问入口，以及重试后无法对上原始调用的问题。
- 解释图表时仍可能生成代码块、露出“应用”动作的问题。

# English

**Diagramon {{version}}** closes the gaps between what the AI panel promised and what it did: explain a diagram, paste two images for comparison, retry a single turn, and land directly on **Review** when a diagram is already open.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still works in the portable build, but updates are delivered as the **installer**
(it never patches the portable folder in place) — download the new ZIP to keep using it.

### Highlights

- **Explain: read-only analysis of the current diagram.** The empty-state action now uses a dedicated
  `Explain` intent. It returns the business context, happy path, module boundaries, error branches and
  risks — **no code fences and no Apply button**, so explaining a diagram can no longer overwrite it.
- **Vision: paste with Ctrl+V, drag files in, and compare two images.** Paste a screenshot straight
  into the Vision dialog, or drop files; up to two images, in upload order. The dialog shows how many
  are selected and both thumbnails remain in the chat. Images stay in memory — never written to disk
  or conversation history.
- **Single-turn actions: retry, edit & resend, delete.** No need to clear a conversation to fix one
  prompt. A retry records the gateway ledger row and sends `Retry-Of` on the next call.
- **Opening the AI panel with a diagram open now lands on Review.** The source-selection “Ask AI to
  edit this” action also goes to Review instead of Generate; an explicitly chosen tab is still kept.
- **Cloud gateway `auto` tier**: choose “Auto tier” in the model menu and the server routes by
  capability and image-input needs.
- **Gateway attribution headers**: `scene` and `retry_of` are sent with gateway requests only;
  BYOK requests never receive these internal metadata headers.
- **More readable conversion log**: AI-enhanced conversions are labelled, with distinct states for
  success, early stop, local fallback, cancellation and failure; rows with a target document open it.

### Fixes

- A second pasted image no longer replaces the first, and both thumbnails are kept.
- The AI panel no longer stays on Generate when a diagram is already open.
- Single-turn actions now have visible, accessible entry points; retries can be tied back to the
  original gateway call.
- Explain no longer produces code blocks or exposes an Apply action.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>
