### 本次亮点

- **DOT → drawio**：在「转换」里选 drawio，Graphviz 先在窗口内算出布局，再把节点、边、标签、子图映射成 drawio 的 mxCell —— 节点中心与预览逐点对齐（≤1px 的量化误差），边端点吸附在形状边界上，不会穿框。
- **子图变成真容器**：`subgraph cluster_*` 转成 drawio 容器，层级按包围盒嵌套还原；拖动子节点时容器跟着动。对话框里可以关掉「子图转容器」，此时如实记为“结构部分保留”。
- **布局沿用你在预览顶栏选的那个**：DOT 用 `dot` / `neato` / `fdp` / … 中当前的引擎，不在转换对话框里再放一个开关 —— 不会出现“预览一个样、画布另一个样”。
- **转换记录能读懂几何**：DOT → drawio 的记录里 `几何 精确`、`样式 近似`，并列出容器映射、形状退化（若有）。

### 修复

- **布局失败不再留下空标签页**：Graphviz 报错（通常带 DOT 行号）直接显示在提示里，不创建目标文档。
- **产物会先自检**：mxfile 写完后立即数一遍节点/边/容器；数不出来就报错，不产出半坏的文件。

# English

**Diagramon {{version}}** brings the DOT lane onto the canvas: converted node positions match the Graphviz preview, edges no longer cut through boxes, subgraphs survive, and the result is ready to drag.

### Downloads

| Option | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Supports **built-in auto-update**; fetches the WebView2 runtime if missing |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

Portable notes: the ZIP contains `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\` — they
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs nothing extra installed: no Node.js, no Chrome, no VC++ redistributable (the exe links the
CRT statically); only the WebView2 runtime that ships with Windows 10/11. “Check for updates” still
finds new releases, but applying one downloads the **installer** (it does not replace the portable
folder in place) — to stay portable, download the new ZIP and overwrite.

### Highlights

- **DOT → drawio** — choose drawio in Convert; Graphviz computes the layout in-window, then nodes,
  edges, labels and clusters are mapped to drawio mxCells. Node centres match the preview point for
  point (≤1px quantisation), and edge endpoints are snapped to shape boundaries so lines never cut
  through boxes.
- **Subgraphs become real containers** — `subgraph cluster_*` maps to drawio containers with nesting
  restored from bounding boxes; dragging a child moves the container. The dialog can turn this off,
  and the report then honestly says “structure partially preserved”.
- **The layout is the one in the preview top bar** — DOT uses the current `dot` / `neato` / `fdp` / …
  engine; the conversion dialog does not offer a second switch, so “preview looks one way, canvas
  another” cannot happen.
- **The conversion record explains geometry** — DOT → drawio records `geometry exact`,
  `style approximate`, and lists container mapping plus any shape fallbacks.

### Fixes

- **A failed layout leaves no empty tab** — Graphviz errors (usually with a DOT line number) are shown
  in the toast, and the target document is not created.
- **The output is self-checked** — the mxfile is counted (nodes / edges / containers) right after
  emission; a mismatch is an error instead of a half-broken file.
