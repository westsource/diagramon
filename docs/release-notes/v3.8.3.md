### 本次亮点

**「对话历史」多了「全部」页**

- 本机**所有**会话按 **文档 / 草稿 / 已失联** 三种归属列出，**未保存文档里的对话也在里面**；
  顶部可按名称、路径或首条提问搜索，还有「共 N 段 · 草稿 M · 已失联 K」的汇总
- 行上的主动作按归属不同：**打开**（文档）/ **恢复**（草稿 → 回到那个未保存的标签页）/
  **恢复为新标签页**（已失联 —— 只带对话与生成的代码，原文件里的手工改动回不来，界面会讲清楚）
- ⋯ 菜单里可以「在文件夹显示 / **导出 Markdown** / 删除这段会话」；
  顶栏还能一键「清理 30 天前的已失联」（二次确认）。草稿与已失联**都不会自动删除**

**外部文件当上下文：入口改成按钮**

- AI 输入框上方那排新增**文件夹按钮（可多选）**，选完即进上下文；把文件**直接拖进 AI 面板**照旧可用。
  不再需要粘贴全路径
- 限制不变：最多 8 份、单份 256 KiB（超了按字符边界截断并标注），只收 UTF-8 文本；
  参考文件与"当前图表源码"在提示里分开措辞，模型不会把参考资料当成要重写的正文

**ELK 离线包：用过才预热**

- 只有你以前把某个 Mermaid 文档的布局选成过 `elk`，才会在启动 3 秒后**后台静默**加载那份 2.4MB
  离线包；没用过的人首次切换布局时才加载 —— 那份包是**一次性且常驻**的成本
  （实测 JS 堆 +7.7MB、进程工作集 +16MB、加载约 0.5 秒），不该让不用的人白背

### 修复

- **导出 PNG 空白**（3.8.2 已修，说明里漏写，这里补记）：位图**不带底色**（暗色主题下浅色笔画在
  白色看图器里几乎一片空白）+ 图大到越过浏览器画布上限（面积 2^28 像素 / 单边 65535）时
  **静默出空图**。现在位图带与预览一致的底色，超大图自动压倍率并在状态栏说明
- **「恢复」按钮折行、「更多操作」按钮被裁掉**：列表动作列的固有宽度被算得偏小，第二颗按钮整颗
  溢出到容器的 `overflow: hidden` 外面；现在动作列按内容定宽、按钮文字不换行，两颗都完整可见可点
- **设置窗口 →「格式与转换」**：窗口从 720 加宽到 880，7 列的注册表表格**不再需要横向滚动**
- **会话列表不再列出历史遗留文件**：会话目录里旧客户端（`default.json`）与原型期留下的 JSON 会被
  正确跳过（以前会显示成一堆「已失联 · 0 轮」），列表也不会再给它们补写 meta

### 说明

- 会话依旧**只存文本**（含思考原文），**图片永不落盘**；删除会话只影响本机这一份，不动你的文件
- 「全部」列表只读轻量元数据（`.meta.json`），不解析会话全文；旧会话首次会被补写一次 meta

# English

**Diagramon {{version}}** completes "you can always find the conversation back": the history dialog gains
an **"All"** page — conversations in unsaved documents show up there, can be opened and restored — plus a
few pixel-level fixes (a wrapping button, a clipped one) and an ELK bundle whose start-up cost is now
"pay only if you use it".

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

**A new "All" page in the conversation history**

- Every conversation on this machine, grouped under **document / draft / unlinked** — **conversations in
  unsaved documents included** — with search over name, path and first prompt, and a
  "N conversations · M drafts · K unlinked" summary
- The row's primary action depends on ownership: **Open** (document) / **Restore** (draft → its unsaved
  tab) / **Restore as a new tab** (unlinked — carries only the conversation and generated code; manual
  edits in the original file do not come back, and the UI says so)
- The ⋯ menu offers **Show in folder / Export Markdown / Delete this conversation**, and the toolbar can
  **prune unlinked conversations older than 30 days** (with confirmation). Drafts and unlinked
  conversations are **never removed automatically**

**External files as context: now a button**

- A **folder button (multi-select)** in the row above the AI input; picked files join the context
  immediately. Dropping files **onto the AI panel** still works. No more pasting full paths
- Same limits: up to 8 files, 256 KiB each (larger ones are cut on a character boundary and labelled),
  UTF-8 text only; reference files and "current diagram source" are worded separately in the prompt

**ELK bundle: pre-warmed only if you have used it**

- The 2.4 MB offline bundle is loaded **in the background 3 s after start-up only if** one of your
  Mermaid documents has ever used the `elk` layout; everyone else loads it on the first layout switch —
  it is a **one-off, permanently resident** cost (measured: +7.7 MB JS heap, +16 MB process working set,
  ~0.5 s to load) and should not be paid by people who never use it

### Fixes

- **Blank PNG exports** (fixed in 3.8.2, missing from those notes — recorded here): bitmaps had **no
  background** (light strokes on a dark theme look blank in any white viewer) and a diagram beyond the
  browser's canvas limit (2^28 pixels of area / 65535 per side) silently produced an **empty image**.
  Bitmaps now carry the same background as the preview, and oversized diagrams get a reduced scale with
  a note in the status bar
- **The "Restore" label wrapped and the "More actions" button was clipped**: the action column's
  intrinsic width came out too small, so the second button overflowed past the container's
  `overflow: hidden`. The column is now sized by content and buttons never wrap — both are fully
  visible and clickable
- **Settings → "Formats & conversion"**: the dialog grew from 720 to 880 so the 7-column registry table
  **fits without a horizontal scrollbar**
- **The conversation list no longer shows legacy files**: old-client (`default.json`) and prototype-era
  JSON in the conversations directory are skipped correctly (they used to show up as a stack of
  "unlinked · 0 turns"), and the list no longer writes metadata for them

### Notes

- Conversations still store **text only** (including reasoning); **images are never written to disk**.
  Deleting a conversation affects only this local copy, never your files
- The "All" list reads only the lightweight `.meta.json` files, never the full conversation bodies; old
  conversations get their metadata back-filled once
