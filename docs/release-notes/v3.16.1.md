# English

**Diagramon {{version}}** makes the overview map show up only when it is useful: it steps aside while the whole diagram fits in the viewport and returns as soon as anything is pushed outside.

### ⚠️ 3.14.5 / 3.15.0 users must update manually

**One character in the update public key shipped in 3.14.5 and 3.15.0 is corrupted**, so those
clients cannot verify any update package (the updater reports `The signature verification failed`).
They will **not** be offered this release and cannot install it automatically. If you are on either
version, download and install {{version}} once by hand; automatic updates work again afterwards.
3.14.4 and older are unaffected and can update via **Help → Check for updates** as usual.

|---|---|---|

| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |
| **Linux AppImage** (no install) | [Download AppImage]({{appimage_url}}) (~{{appimage_size_mb}} MB) | `chmod +x` and run; AppImage supports in-app auto-update |
| **Linux deb** (Debian / Ubuntu) | [Download deb]({{deb_url}}) (~{{deb_size_mb}} MB) | Install with your package manager; needs WebKitGTK 4.1; **no** in-app auto-update |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.

### Highlights

- **The overview map appears on demand**: when the whole diagram fits inside the preview viewport,
  the map in the lower-right hides itself; as soon as any element is outside (zoom, pan, smaller
  window) it comes back. The test is “is every element visible”, not a zoom percentage.
- **No mid-drag disappearance**: while dragging the viewport frame inside the map it stays visible;
  the decision is re-evaluated on release, so navigation never vanishes under the pointer.
- **The toggle still wins**: with the map switched off in the toolbar or settings, it stays hidden
  regardless of what is outside the viewport.
- **Same rule for text and canvas formats**: Mermaid / DOT / D2 use the rendered SVG content box,
  drawio / Excalidraw use the content and viewport boxes from their host page, with a half-pixel
  tolerance so the panel does not flicker at the boundary.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, D2, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>
