# 中文

**Diagramon {{version}}** 把 AI 的思考过程做成了一块**可折叠**的内容：思考型模型（GLM / DeepSeek /

### 本次亮点

- **思考过程可以折叠了**：推理块的摘要行本身就是开关 —— 点一下、或按 Enter / 空格即可展开与收起，
  鼠标悬停与提示文案都会告诉你它能点。默认时机也按"你现在要看什么"来定：流式期间展开（看得见它在干活），
  **有正文**的收尾自动收起（把视线还给正文），**没有正文**的那一轮仍然展开（那时推理就是这一轮唯一的产出）。
- **你的选择不会被界面改回去**：手动折叠或展开之后，切页签、切文档、界面重排都不会把它打回默认 ——
  折叠状态跟着那一轮消息走。
- **展开读到的是完整原文**：流式期间只渲染最新一段（每帧都要重写这一块，不能把几万字符反复重排），
  收尾后展开给的是完整推理，框内可滚动。

### 修复

- 有正文的那一轮，推理原文不再在收尾时被整块丢掉 —— 那是这一轮真实计费的产出，事后再想读就没了。
- **被输出上限截断、或中途断流，不再一声不吭**：正文被本档输出上限切断（上游回 `finish_reason=length`）、
  连接在生成途中断开时，气泡上会明确写清发生了什么，并说明上面那段是已经收到的部分。以前这两种收尾
  与正常收尾在界面上一模一样（真机实录：界面走到「5906 tok」就没了下文，没有任何提示）。
- mermaid 的引号标签不再被误报：`A["连续失败 >= 5?"]` 这类写法以前会报「括号没有闭合」。

# English

**Diagramon {{version}}** turns the AI's reasoning into a **collapsible** block: thinking models
(GLM / DeepSeek / Qwen family) push their chain of thought frame by frame before the answer arrives,
and what used to be discarded the moment a turn ended can now be folded away and opened again at will.
On top of that, a turn that was **truncated** or whose stream **dropped mid-flight** now says so —
those endings no longer look exactly like a normal finish.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **The thinking block folds.** The summary row *is* the toggle: click it, or press Enter / Space, to
  collapse and expand; hover styling and a tooltip say so. The default follows what you need at that
  moment — expanded while streaming (you can see it working), collapsed automatically once the turn
  ends **with** answer text (so the answer gets your attention), and still expanded for a turn that
  produced **no** answer text (there the reasoning is the only output).
- **Your choice sticks.** After you fold or unfold it by hand, switching tabs, switching documents and
  re-rendering the panel never reset it — the state belongs to that turn's message.
- **Expanding gives you the whole transcript.** While streaming only the newest stretch is rendered
  (the block is rewritten every frame, so tens of thousands of characters cannot be re-laid out each
  time); once the turn is over, expanding shows the full reasoning, scrollable in place.

### Fixes

- A turn that produced answer text no longer throws the reasoning away when it ends — that reasoning
  was billed output, and it used to be gone for good.
- **Truncated or interrupted streams say so** — when the answer is cut off by your tier's output
  ceiling (the upstream returns `finish_reason=length`), or the connection drops mid-generation, the
  bubble states what happened and that what you see above is only the part that arrived. Both endings
  used to look exactly like a normal finish (field report: the UI just stopped at "5906 tok", with no
  message at all).
- No more false "unclosed bracket" reports on mermaid quoted labels such as `A["连续失败 >= 5?"]`.
