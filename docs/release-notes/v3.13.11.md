### 本次亮点

- **drawio / Excalidraw 现在也支持自动配色。** 顶栏出现「配色」；选色系后直接把颜色写进画布文件：
  drawio 改写每个 cell 的 `fillColor/strokeColor/fontColor`，Excalidraw 改写元素的
  `strokeColor/backgroundColor` 与绑定文本颜色。原色与色系存在文件里，**换色、清除、
  保护手写颜色**都能做；清除会把颜色恢复成原来的样子。
- **Mermaid 转 drawio 输出「干净」的 drawio 文件。** 不再保留导入器加的
  `<UserObject>` / `mermaidData` / `mermaidBaseStyle` 元数据，节点和边就是普通
  `<mxCell>` + `<mxGeometry>`；标签、连线、几何全部保留，drawio 里可继续拖拽编辑。
- **切回 drawio 标签不再偏到左上角。** 首次挂上/切回画布文档时，会等承载页把图加载出来
  再自动适应并居中；同一份文档的编辑重渲染不会重置你自己调过的缩放与位置。

### 修复

- 画布配色会把 Mermaid→drawio 转换出来的 `light-dark(...)` 主题默认色误判为「手写颜色」，
  导致整张图被跳过 —— 现在识别为主题默认色，照常上色。
- Excalidraw 的外层容器与内部节点会被分到同一个颜色槽 —— 现在按 `groupIds` / frame /
  矩形包含关系分组，内外层拿到不同颜色；分组取色的组数也修正为真实值（之前固定为 1）。
- drawio 保存时会把带 `UserObject` 的旧图重新导出 —— 转换后强制重载画布并等干净 XML 生效。

# English

**Diagramon {{version}}** closes three canvas gaps at once: color schemes, clean conversion and viewport.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **drawio / Excalidraw now support color schemes.** The toolbar shows a “Colors” control; picking a
  scheme writes colors into the canvas file: drawio updates each cell's
  `fillColor/strokeColor/fontColor`, Excalidraw updates element `strokeColor/backgroundColor` and the
  bound text color. Original colors and the scheme are stored in the file, so **switching, clearing
  and protecting hand-painted colors** all work; clearing restores the original colors.
- **Mermaid → drawio now produces a clean drawio file.** The importer's `<UserObject>` /
  `mermaidData` / `mermaidBaseStyle` metadata is removed; nodes and edges are plain
  `<mxCell>` + `<mxGeometry>`. Labels, connectors and geometry are preserved and remain editable
  in drawio.
- **Switching back to a drawio tab no longer jumps to the top-left.** When a canvas document is
  first mounted or switched back to, the app waits for the carrier to load the diagram, then fits
  and centers it; ordinary re-renders keep your own zoom/position.

### Fixes

- Canvas coloring treated `light-dark(...)` theme defaults produced by the Mermaid→drawio importer as
  hand-painted colors and skipped the whole diagram — they are recognized as defaults now.
- Excalidraw outer containers and inner nodes shared one color slot — colors are now grouped by
  `groupIds` / frame / rectangle containment, and the real group count is used when picking hues
  (it was hard-coded to 1).
- Saving a converted drawio could re-export the old `<UserObject>` graph — the canvas is reloaded
  after flattening and the clean XML is awaited before save.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

  ship inside the installer
