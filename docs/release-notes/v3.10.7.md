### 本次亮点

- **AI 回复的「拷贝源码」改为图标按钮**：文案收进 `title` / `aria-label`，消息头不再被长文字挤占；
  点击仍然一次拷走这条回复全部产出的源码（没有代码块时拷正文）。
- **用户消息新增一键拷贝**：在「我」的消息头加了同款 `copy` 图标，点一下就把自己发出的内容
  写进剪贴板，不用再选中文本手动复制。
- **拷贝按钮与旁边的操作按钮完全同一套样式**：拷贝、编辑并重发/重新生成、删除都收进同一个
  按钮组，同尺寸、同间距、悬停时整组一起显现（此前拷贝单独常亮、padding 也不同，看着像另一种控件）。
  悬停有「拷贝源码」/「拷贝输入」提示；拷贝成功提示「已复制」，失败仍会如实提示剪贴板写入失败。
- **修复「我」方消息上「编辑并重发」「删除这一轮」点了没反应**：新发出的用户消息此前没带页签标记，
  点按钮时找不回自己那一轮；现在两者都能正常把原文填回输入框、或成对删除整轮对话。
- **继续包含前两版的修复**：3.10.6 的 Mermaid 虚线/`linkStyle` 修复，以及 3.10.5 的
  「解图」Markdown 预览与源码切换。

# English

**Diagramon {{version}}** unifies message copying in the AI panel as icon buttons: copy AI replies and your own input with one click, in exactly the same style as the edit-and-resend / regenerate buttons — and fixes those buttons doing nothing on your own messages.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **“Copy source” on AI replies is now an icon button**: the label moved to `title` / `aria-label`, so
  the message header is no longer crowded. Clicking still copies all source produced by that reply
  (or the prose when there is no code block).
- **One-click copy for your own messages**: the “me” message header now has the same copy icon; one click
  puts your input on the clipboard — no more selecting text by hand.
- **The copy button now matches the neighbouring action buttons exactly**: copy, edit-and-resend /
  regenerate, and delete all live in one button group with the same size, spacing, and hover reveal
  (copy used to stay fully opaque with different padding, looking like a different control).
  Tooltips still read “Copy source” / “Copy input”; success shows “Copied”, and clipboard failures are
  still reported honestly.
- **Fixed “Edit and resend” / “Delete this turn” doing nothing on your own messages**: newly sent user
  messages were missing their tab marker, so the buttons could not locate the turn. Both now work —
  the original text goes back into the input, or the whole turn is deleted as a pair.
- **Includes the previous two fixes**: the Mermaid dashed-link fix from 3.10.6 and the Explain Markdown
  preview/source toggle from 3.10.5.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer
