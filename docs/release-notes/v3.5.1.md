# English

**Diagramon {{version}}** is a small fix release: it fills in several loose ends from 3.5.0 — the Help
menu now has a **D2 reference** entry (all three official-docs links really open the system browser), and
a batch of UI strings — the source window's search panel above all — finally follow the chosen language.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### What changed

- **New "D2 reference" entry in the Help menu**, next to "Mermaid docs" and "Graphviz DOT reference".
  Those three used to be placeholders: clicking only showed "Offline-first: documentation links are not
  opened externally". They now **open the official documentation in your system browser**
  (D2 → d2lang.com/tour/intro, DOT → graphviz.org language reference, Mermaid → mermaid.js.org).
  If the browser cannot be opened, the URL is echoed in the toast — no silent failure.
- **The source window's find & replace panel is fully localized**: it used to stay English even in the
  Chinese UI (Find / Replace / next / previous / match case / regexp / by word / replace all / close).
- **A batch of UI tooltips now follow the language**: title bar, tab strip, preview toolbar, zoom,
  drag handles, every icon button of the AI panel, and the command palette's hint text — 34 places in
  total (they used to stay Chinese in the English UI).
- **Copy fixes**: the Problems panel, About dialog and Operations guide no longer say "four formats"
  (there are five now, D2 included); the guide's formats and conversion sections now cover D2's three
  layout engines and its three conversion directions.
- **Accessibility/casing details**: the canvas iframe's accessible title, the shortcut-table cells that
  contained Chinese words, and the two degraded screens (capture page / boot failure) are localized too.
- Maintenance: the `check.mjs` i18n gate got stricter — besides "every used key exists on both sides",
  it now also verifies **key-set symmetry** and **placeholder parity per key**.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, D2, drawio and
Excalidraw can all be edited with live preview, with AI assistance for generation, review and image
recognition. Rendering and validation work with no network at all — code or images reach a model only
when you actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the rendering runtimes and front-end assets
  all ship inside the installer
