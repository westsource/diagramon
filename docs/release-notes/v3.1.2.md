- **源码窗口支持 Tab 缩进 / Shift+Tab 反缩进**：光标所在行整行右移一格（4 空格），跨行选区

# English

**Diagramon {{version}}** is an editor release: the source window finally gets **Tab indentation** —
until now pressing Tab inside it moved focus out of the editor, so indenting simply did not work.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Tab indents, Shift+Tab outdents in the source window**: the caret's line shifts right by one
  indent unit (4 spaces), a multi-line selection is **block-indented**, and Shift+Tab strips up to one
  level of leading whitespace per line — matching the 4-space indentation that Mermaid / DOT bodies use.
- **Tab no longer throws focus out of the editor.** That was the actual symptom: pressing Tab in the
  source window jumped to the next control in the window and left the document untouched — indentation
  effectively did not exist. Tab is now handled inside the editable area only, which also keeps
  **Ctrl+Tab tab switching** and the Tab behaviour of the find/replace panel's own inputs intact.
- **The indent is a single standard edit transaction**: one Ctrl+Z reverts the whole thing.
- The keyboard shortcut sheet (**Help → Keyboard shortcuts**) now lists `Tab / Shift+Tab`.
- The **current-line highlight** (gutter highlight + line background) and Tab indentation are both
  covered by the automated UI assertions now (21 → 22 probe assertions), so neither can silently
  disappear when the bundled editor asset is next rebuilt.
