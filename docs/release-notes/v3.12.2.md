### 本次亮点

- **按区块上色**：Mermaid 的 `subgraph`、DOT 的 `cluster`、D2 的容器，现在都是分组依据 ——
  同一个区块里的节点同色相，不同区块不同色相（最多 9 档，22 个子图的图也不会糊成一片）。
- **框也跟着染色**：区块自己的边框会铺同色相、但比节点浅一档的底色，
  一眼就能看出"这是哪一块"，节点也不会溶进背景。
- **语义角色优先**：`判断 / 入口 / 数据 / 外部 / 异常` 这些角色仍然盖过分组色 ——
  "这里会出事"不会被区块色吃掉；只有没有语义特征的普通节点才按分组上色。
- **展平感消失**：真实架构图里七八成节点是普通节点，以前会全部落到同一个主色；
  现在它们按所属子系统分开，色号不用再调。
- 只包着子分组的"外壳"区块也会分到自己的颜色，不再残留成默认的淡黄框。

### 修复

- **清掉颜色后仍然上不了色**：以前只要节点上留着任何自定义类名就算"已有颜色"，
  于是删掉 `classDef` 行（最自然的清色方式）之后，残留的 `:::目录` 会让近八成节点被静默跳过。
  现在只有**真的定义了填色**的类才算手写颜色。
- **D2 图多出假节点**：`classes: { … }` 里的 `fill:` / `stroke-width:` / `shape:` 曾被当成节点，
  文末给它们各写三行样式；现在整块跳过，行内 `{class: …}` 也能正确识别。
- **标签猜词盖过分组**：分层架构图几乎每个标签都带"数据"，会让整张图被染成同一个数据紫；
  优先级改为 显式角色 > 形状 > 分组 > 标签 > 主链路。

# English

**Diagramon {{version}}** teaches auto-coloring where a node *lives*, not just what it *is*
(entry / decision / data / external / risk).

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Color by region**: Mermaid `subgraph`s, DOT `cluster`s and D2 containers are now grouping keys —
  nodes inside a block share a hue, different blocks get different hues (up to nine, so a diagram
  with 22 subgraphs still reads clearly).
- **Frames get tinted too**: each block's border gets the same hue, one step lighter than its nodes,
  so the region is obvious and the nodes still stand out.
- **Semantic roles win**: `decision / entry / data / external / risk` still override the group color —
  "something goes wrong here" is never swallowed by a region tint. Grouping only colors plain nodes.
- **No more flatness**: in real architecture diagrams 70–80% of nodes are plain, and they all used to
  collapse into one color; now they separate by subsystem, without touching the palette itself.
- Wrapper blocks that only contain other blocks also get their own tint instead of staying default yellow.

### Fixes

- **Nothing got colored after clearing by hand**: any leftover custom class name used to count as
  "already colored", so deleting the `classDef` lines (the most natural way to clear) left `:::catalog`
  markers behind and roughly 80% of nodes were silently skipped. Now only a class that **actually sets
  a fill** counts as a hand-picked color.
- **Phantom nodes in D2 files**: `fill:` / `stroke-width:` / `shape:` inside `classes: { … }` were parsed
  as nodes and styled at the end of the file; those blocks are skipped now, and inline `{class: …}` is parsed.
- **Label guesses overriding structure**: layered diagrams have "data" in almost every label, which
  painted a whole chart in one violet. Priority is now explicit role > shape > group > label > main.
