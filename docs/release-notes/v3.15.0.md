### 本次亮点

- **只读分享链接**：标签条上的「共享」按钮（也可从右键菜单、文件菜单、命令面板 `Ctrl+Alt+S` 进入）可以把当前图表生成一个只读链接。云端文档直接创建；本地未上传的文档会先上传再创建；未登录会先引导登录；已分享的文档可在同一对话框里查看与撤销。
- **分享页按分享者的样子显示**：链接会记住创建时的布局与 Mermaid 外观（主题、字体等），访客看到的是你当时的样子，而不是客户端默认样式。
- **只读分享页适配**：网页版分享页隐藏编辑区与工作区 chrome，密码页、失效页各自单卡片呈现；所有界面资源改用根绝对路径，直接打开 `/s/<token>` 不再 404。
- **「使用在线版」自动登录**：已登录客户端会先向云端换取一张 60 秒有效的网页登录票据，再打开 `app.diagramon.com` —— 浏览器里没登录也能直接进入；换票失败或未登录时退回普通链接，按钮永远可用。
- **标签条按钮换位**：「共享」与「转换」按钮位置调换，转换在前、共享在后，与菜单顺序一致。

# English

**Diagramon {{version}}** adds read-only share links and makes "Use the online version" sign you in automatically when the desktop app is already logged in.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (Windows, recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (Windows, no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |
| **Linux AppImage** (no install) | [Download AppImage]({{appimage_url}}) (~{{appimage_size_mb}} MB) | `chmod +x` and run; **in-app auto-update supported** |
| **Linux deb** (Debian / Ubuntu) | [Download deb]({{deb_url}}) (~{{deb_size_mb}} MB) | Install with your package manager; needs WebKitGTK 4.1; **no** in-app auto-update (download the new version) |

Windows portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable — only the system
WebView2 runtime that comes with Windows 10/11.

Linux notes: the AppImage is a single file — `chmod +x Diagramon_*.AppImage` and run it; the deb suits a
fixed desktop and registers the five diagram extensions (.mmd/.dot/.d2/.drawio/.excalidraw).

### Highlights

- **Read-only share links**: the "Share" button on the tab strip (also in the context menu, the File menu and the command palette via `Ctrl+Alt+S`) turns the current diagram into a read-only link. Cloud documents are shared directly; local unsaved ones are uploaded first; signed-out users are asked to sign in first; already-shared documents can be reviewed and revoked from the same dialog.
- **The share page looks like the sharing author left it**: the link carries the layout and Mermaid appearance (theme, fonts, …) in effect at creation time, so visitors see your rendering rather than client defaults.
- **Read-only share page**: the web share page hides the editor and workspace chrome, with single-card password and expired-link screens; all UI assets now use root-absolute paths so opening `/s/<token>` directly no longer 404s.
- **"Use the online version" signs you in**: a logged-in client first exchanges a 60-second web sign-in ticket with the cloud, then opens `app.diagramon.com` — you land signed in even when the browser has no session. If the exchange fails it falls back to the plain URL, so the button always works.
- **Tab-strip buttons reordered**: "Share" and "Convert" swapped places (convert first, share second) to match the menu order.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>
