### 本次亮点

**AI 对话不再丢**

- **未保存文档的对话也会保存**：新建文档（还没另存为）里的 AI 对话，以前从不落盘、
  关掉就没了；现在按**草稿**保存，重启应用后照常找回
- **AI 生成完一键"应用成新标签页"时，对话跟着产物走**：生成结果落在哪个标签页，
  这段对话就同时出现在那里 —— 不会再出现"对话留在旧文档、产物在新文档"的分家
- **保存文件后对话自动跟着文件走**：草稿会话在你保存 / 另存为的那一刻迁移到文件身份下；
  重命名、移动文件之前的对话也不会因为"另存为"而留在旧路径上
- **对话按归属落盘，不再按"当前活动标签页"**：流式生成过程中切到别的标签页，
  回复仍然回到它原本的对话里 —— 以前这样切一次就会丢一轮
- 保存失败会提示一次（以前失败被静默忽略）

**窗口与转换**

- **关闭到托盘（按设置）**：设置 → 外观开启后，点 ✕ 只隐藏窗口，从托盘图标可恢复或退出；
  再次点托盘图标 = 唤回窗口。托盘图标常驻，两种设置下都能从那里退出
- **Mermaid → Excalidraw 沿用文档外观**：源码文档在顶栏选了 classic / neo / handDrawn，
  转换出的 Excalidraw 按同一 look 渲染；转换记录里如实注明沿用了什么、布局按引擎默认重排
- **设置窗口可以滚动了**：面板曾被外层容器整体裁掉（max-height 放开导致的布局问题），
  现在内容超出时面板自己出滚动条

### 说明

- 未保存文档打开「历史」对话框，提示语已改为"对话已按草稿保存；保存文件后会跟着文件走"
- 草稿对话在「历史」列表里的集中浏览（含已失联会话的恢复）将在下个版本提供

# English

**Diagramon {{version}}** fixes a class of "lost conversations" and pushes the window and
conversion story forward: the close button can minimize to the system tray (opt-in), converting
Mermaid to Excalidraw now honors the look you picked in the top bar, and the settings dialog
finally scrolls.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

**AI conversations no longer get lost**

- **Conversations in unsaved documents are now persisted**: AI chats in a brand-new
  (not-yet-saved) document used to never touch the disk; they are now stored as a **draft**
  and can be found again after a restart
- **"Apply as a new tab" carries the conversation along**: wherever the generated code lands,
  the conversation appears there too — no more split between the chat and the diagram
- **Saving the file migrates the conversation**: the draft conversation moves to the file's
  identity the moment you save / save-as, so "Save As" no longer leaves the history behind
  on the old path
- **Conversations are persisted by ownership, not by the active tab**: switching tabs while
  a reply is streaming no longer drops that round
- A failed save now warns once instead of failing silently

**Window & conversion**

- **Minimize to tray on close (opt-in)**: enable it under Settings → Appearance and the ✕
  button only hides the window — restore or quit from the tray icon; clicking the tray icon
  again brings the window back. The tray icon is always present, so quitting from it works
  either way
- **Mermaid → Excalidraw honors the document look**: if the source document picked
  classic / neo / handDrawn in the top bar, the converted Excalidraw renders with the same
  look; the conversion record states honestly what carried over (layout is arranged by the
  engine default)
- **The settings dialog scrolls**: the pane used to be clipped by its container as a whole;
  now the pane scrolls on its own when content exceeds the visible area

### Notes

- Conversations still store **text only** (including reasoning text); **images are never
  written to disk** — that promise is unchanged
- The "History" dialog for an unsaved document now reads "the conversation is stored as a
  draft and will follow the file once you save it"
- A dedicated browsing UI for all conversations (including recovering unlinked ones) is
  planned for the next release
