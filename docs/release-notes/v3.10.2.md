### 本次亮点

- **格式显示次序统一为 drawio → Mermaid → Excalidraw → Graphviz DOT → D2**。
  「新建」子菜单、标签条「转换」下拉、「转换能力一览」的方向清单与矩阵、命令面板
  全部沿用这一份顺序，不再出现「下拉一套、说明页另一套」。
- **「转换」下拉与「转换能力一览」逐条同序**。Mermaid 源现在两边都是
  drawio → Excalidraw → DOT → D2。
- **快捷键真正接上**：`Ctrl+K Ctrl+T`（切换明暗主题）、`Ctrl+K Ctrl+S`（打开快捷键总表）
  此前只在菜单里印着、按下去没有反应，现在按 VS Code 的两段键生效；
  菜单里的 `Shift+Alt+F`（格式化源码）也补上了绑定。
- **「快捷键总表」按实现重写**：改正 `Alt+1…Alt+5` 的说法（实际是 Alt+1 资源管理器 /
  Alt+2 聚焦搜索 / Alt+4 云端文档 / Alt+5 大纲），补上 `Ctrl+R`（文件历史）、
  `Ctrl+Tab` / `Ctrl+Shift+Tab`（切换标签）、`Ctrl+Shift+C`（复制预览图）、`Ctrl+Q`（退出），
  侧栏视图描述也同步成「资源管理器 / 云端文档 / 大纲」。
- **菜单文案统一**：帮助里的 `键盘快捷键总表` → `快捷键总表`、`操作说明` → `使用指南`，
  三条格式文档统一叫「… 文档」；视图里的 `外观与设置…` → `设置…`，
  视图模式压缩为 `仅源码 / 分屏 / 仅预览`、`全屏预览`；文件菜单里的
  `搜索内容` → `在工作区中搜索`、`更多…（含搜索过滤）` → `打开历史…`，
  子菜单项不再带多余的省略号。
- **使用指南修订**：转换段落改回真实方向（`DOT → D2` 从来不存在，DOT → Mermaid 仍是实验方向；
  不可用方向统一去「帮助 → 转换能力一览」看），AI 段落补上「解释当前图」这一只读用法。

### 修复

- 「转换能力一览」窗口不再标注「只读」——它本来就只解释能力，两个多余的字反而像另一个功能入口。
- 「转换为」下拉的次序与说明页不一致（同一个 Mermaid 源会看到两套次序）。
- 快捷键总表里三处与实现不符的描述（组合键、活动栏视图、侧栏视图清单）。

# English

**Diagramon {{version}}** is the release where the documentation matches the code: conversion order, menu wording and both help reference pages are now aligned with what actually ships — and the shortcuts that were only printed in menus finally work.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still works in the portable build, but updates are delivered as the **installer**
(it never patches the portable folder in place) — download the new ZIP to keep using it.

### Highlights

- **One display order everywhere: drawio → Mermaid → Excalidraw → Graphviz DOT → D2.**
  The New submenu, the tab-bar Convert dropdown, the Conversion reference list and matrix,
  and the command palette all read that single order — no more "dropdown says one thing,
  the reference says another".
- **The Convert dropdown now matches the reference line by line.** For a Mermaid source both
  read drawio → Excalidraw → DOT → D2.
- **Shortcuts are actually wired:** `Ctrl+K Ctrl+T` (toggle theme) and `Ctrl+K Ctrl+S` (shortcut
  reference) were printed in menus but did nothing; they now work as VS Code-style chords, and
  `Shift+Alt+F` (format source) gained its missing binding.
- **The shortcut reference was rewritten against the implementation:** the `Alt+1…Alt+5` claim is
  corrected (Alt+1 Explorer / Alt+2 focus search / Alt+4 cloud documents / Alt+5 outline), and
  `Ctrl+R` (file history), `Ctrl+Tab` / `Ctrl+Shift+Tab` (cycle tabs), `Ctrl+Shift+C` (copy preview)
  and `Ctrl+Q` (quit) are now listed; the sidebar description matches today's views.
- **Menu wording tightened:** Help has `Shortcut reference` / `User guide` and three uniformly named
  format docs; View has `Settings…`, `Source only / Split / Preview only`, `Full-screen preview`;
  File has `Search in workspace` and `Open history…`, and submenu entries no longer carry a
  misleading ellipsis.
- **User guide corrected:** the conversion section now states the real directions (`DOT → D2` never
  existed; DOT → Mermaid is experimental) and points unavailable directions to Help → Conversion
  reference; the AI section documents the read-only "explain this diagram" usage.

### Fixes

- The Conversion reference no longer says "(read-only)" — it only ever explains capabilities, and
  the two extra words made it look like a second action entry.
- The Convert dropdown and the reference page used different orders for the same source.
- Three descriptions in the shortcut reference disagreed with the code (chords, activity-bar
  views, sidebar view list).
