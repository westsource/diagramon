### 本次亮点

- **一条时间线**：生图、识图、改图、解图不再各占一个页签；同一文档的对话按时间顺序排在一起，
  回看与重试都只面对一份历史。
- **四档意图滑块**：发送前直接看到本条消息的意图。点任意一档即手动覆盖，点「回自动」恢复；
  发送后覆盖自动清掉，下一句重新判定。
- **可选自动判定**：设置里可开启 Jev / System One 兼容判定端点。开启后输入停顿时预判，
  显示置信率；端点超时、未配置密钥或低置信都只回退到当前档位，**绝不阻塞发送**。默认关闭。
- **输出格式下拉**：新增「跟随当前 / Mermaid / Graphviz DOT / D2 / drawio / Excalidraw」。
  目标格式与当前文档不同时，应用会新建对应格式的标签页；drawio / Excalidraw 由承载页导入器
  从 Mermaid 现场转换，不要求模型直接写画布 XML/JSON。
- **识图仍是硬规则**：附了图片就是识图；没有活动文档就是生图，不把这两类交给分类器猜。
- **解图保持只读**：解图的空态仍有主按钮和三个角度词，回复不产生代码卡、不写入文档。

### 修复

- 生成请求在意图判定尚未完成时重复点击发送，会重复发起同一句话（两次真实计费）；

# English

**Diagramon {{version}}** reworks the AI panel entry point: instead of four tabs there is one
continuous timeline, and every message shows — and lets you change — which of
Generate / Vision / Review / Explain it will be sent as.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **One timeline**: Generate, Vision, Review and Explain no longer own separate tabs; a document's
  conversation is one chronological history, so review and retry face a single record.
- **Four-way intent slider**: see each message's intent before sending. Click any stop to override,
  click “Auto” to return. The override clears after sending, so the next sentence is classified anew.
- **Optional automatic classification**: enable a Jev / System One compatible endpoint in Settings.
  While you type, pauses are classified and the confidence is shown. Timeouts, a missing key or low
  confidence only fall back to the current stop; sending is **never blocked**. Off by default.
- **Output format selector**: Follow current / Mermaid / Graphviz DOT / D2 / drawio / Excalidraw.
  When the target differs from the current document, applying opens a new tab in that format.
  drawio and Excalidraw are converted from Mermaid by the carrier's importer, so the model is never
  asked to write canvas XML/JSON directly.
- **Vision stays a hard rule**: an attached image means Vision; no active document means Generate.
  Neither is left to the classifier.
- **Explain stays read-only**: its empty state keeps the primary action and three angle chips;
  replies produce no code card and never write to the document.

### Fixes

- Double-clicking Send while intent classification was still in flight could fire the same sentence
  twice (two billable calls). Send is now locked during classification.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer
