### 修复

- **Mermaid 标签含闭合符号被截断**：如 `D["...byte[]"]` 这类正文里带 `]` 的标签，转换时会在第一个
  `]` 处被截掉后半段，导致标签残缺、甚至报解析错误。现在按配对逻辑正确闭合，标签完整保留。
- **首行 UTF-8 BOM 识别失败**：带 BOM 的文件，头部识别曾把 BOM 当成正文的一部分而判错格式；
  现在先剥离 BOM 再识别。
- **D2 导出静默丢孤立节点**：见上方亮点——之前四项内容全空的节点会被丢掉，现在不会。
- **撇号被误当引号起始**：Mermaid 标签正文以撇号开头（如 `A['quoted]`）时，转换器曾把撇号当成
  引号包裹的起点而误判，且对应的回归测试断言不足、是靠兜底碰巧通过的；现在逻辑与注释一致，
  标签完整保留，回归断言也补强。

# English

**Diagramon {{version}}** focuses on converter quality and editor polish: it fixes four real defects in
Mermaid and D2 conversion (broken labels, dropped nodes) and improves the "recently opened" list and
the activity-bar entries.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **"Recently opened" is no longer capped**: the history list is now unlimited with lazy-loaded paging
  inside the window — no stutter however far you scroll.
- **Cleaner activity bar**: the "Settings" and "Keyboard shortcuts" entries swapped positions so the
  most-used path feels more natural.
- **D2 export no longer drops nodes**: an isolated node with no label, no subshape, no icon and no link
  was previously **silently omitted** from the exported D2 file, so it no longer matched the source.
  Now even a node with all four fields empty is written out — export matches your canvas exactly.
- **More fixes**: labels containing closing brackets, a leading BOM, and a mis-parsed apostrophe are all
  handled correctly (see below).

### Fixes

- **Mermaid labels containing a closing bracket were truncated**: a label such as `D["...byte[]"]` was
  cut off at the first `]`, leaving a broken label or a parse error. Brackets now close correctly and
  the label is preserved whole.
- **A leading UTF-8 BOM broke header detection**: for BOM-prefixed files the BOM was treated as part of
  the body and the format was misdetected. The BOM is now stripped before detection.
- **D2 export silently dropped isolated nodes**: see above — nodes with all four content fields empty
  were omitted; now they are always written.
- **Apostrophe misread as a quote start**: when a Mermaid label begins with an apostrophe (e.g.
  `A['quoted]`), the converter treated the apostrophe as the start of a quoted wrapper and mis-parsed
  it, and the regression test's assertion was too weak to catch it (it passed by luck via a fallback).
  The logic now matches its comment, the label is preserved whole, and the assertion is strengthened.
