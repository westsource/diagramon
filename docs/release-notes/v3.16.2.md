### 本次修复

- **Mermaid → D2 转换后不再编译失败**：转换产物里的容器是 `accessLayer: "接入层" { … }`，
  自动配色此前把整段 `accessLayer: "接入层"` 当成容器名，写出
  `"accessLayer: \"接入层".lb.style.fill` 这种不存在的节点路径；容器外的边又被整体加引号，
  D2 把 `"组.节点"` 当成一个普通节点，`(…)[0].style.stroke` 报 `indexed edge does not exist`。
  现在容器只取引号外第一个冒号前的 id，边端点解析回真实节点的点号路径。
- **subgraph 样式不再丢**：Mermaid 的 `style <子图> fill:…,stroke:…,color:…` 现在写进对应的
  D2 容器块（`style.fill` / `style.stroke` / `style.font-color`），此前会被静默丢弃。
- **回归覆盖**：新增容器标签、组内边、转换+上色整链路、容器样式 4 组测试；产物经 D2 引擎实际编译验证。

# English

**Diagramon {{version}}** fixes a required step in Mermaid → D2 conversion: applying the palette right after converting corrupted node paths for labelled containers, and the D2 preview then failed with `indexed edge does not exist`. Subgraph styles are now migrated too.

### ⚠️ 3.14.5 / 3.15.0 users must update manually

**One character in the update public key shipped in 3.14.5 and 3.15.0 is corrupted**, so those
clients cannot verify any update package (the updater reports `The signature verification failed`).
They will **not** be offered this release and cannot install it automatically. If you are on either
version, download and install {{version}} once by hand; automatic updates work again afterwards.
3.14.4 and older are unaffected and can update via **Help → Check for updates** as usual.

### Fixes

- **Mermaid → D2 output no longer fails to compile after auto-colouring**: containers are emitted as
  `accessLayer: "接入层" { … }`, but the palette scanner treated the whole
  `accessLayer: "接入层"` as the container name and wrote a non-existent path such as
  `"accessLayer: \"接入层".lb.style.fill`. Edges outside containers were also quoted as a whole, so
  D2 saw `"group.node"` as one plain node and `(…)[0].style.stroke` failed with
  `indexed edge does not exist`. The scanner now takes the id before the first unquoted colon and
  resolves edge endpoints back to real dotted node paths.
- **Subgraph styles are preserved**: Mermaid `style <subgraph> fill:…,stroke:…,color:…` is now written
  into the matching D2 container (`style.fill` / `style.stroke` / `style.font-color`) instead of being
  silently dropped.
- **Regression coverage**: four new tests (labelled containers, edges inside containers, the full
  convert+colourize pipeline, container styles); the output was compiled with the real D2 engine.
