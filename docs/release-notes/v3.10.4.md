### 本次亮点

- **新增「解图」页签**（AI 面板第 4 个）：只读解读当前图 —— 它描述什么、主链路怎么走、
  模块边界在哪、哪些异常分支或设计风险值得注意。**不产出代码、没有「应用」按钮、不动文档**。
  回复落在这个页签自己的会话里，按文档持久化，「历史会话」里照样找得回。
- **四条直接入口**，都指向同一件事：
  - AI 菜单 →「解图：只读解读当前图」
  - 快捷键 **`Ctrl+Shift+E`**
  - 命令面板（`Ctrl+Shift+P`）→「解图…」
  - 预览顶栏的「解图」按钮，或**文档标签右键 →「解图（只读解读）」**
  面板空态另给一个主按钮与三个角度词（讲什么 / 主链路 / 风险），点一下直接发。
- **`Ctrl+Shift+E` 在面板收起时也能用**：按下就把面板打开、切到「解图」并开始解读。
- **渲染区域尺寸变化时自动适应视图**（新增设置，默认开，见「设置 → 编辑器」）：
  拖分隔条、开合侧栏 / AI 面板 / 底部面板、切视图模式、缩放窗口之后，图会按新尺寸重新适应并居中，
  等同点一次「适应视图」。不想要这个联动可以关掉，关掉后视口只在打开/切换文档与显式适应时变。
- **AI 页签改名**：原来的「对话生成」改为「生图」，与旁边「识图」「改图」「解图」四个动作对齐。

### 修复

- **「解释这张图在讲什么」不再变成画图**：「生图」页签里的那颗建议词以前只是把文字填进输入框，
  发出去的是"画一张图"的意图；现在它直接落到「解图」页签按只读意图发。
- **恢复出来的历史会话重试时不会走错意图**：从磁盘还原的轮次以前丢了所属页签，
  在「改图」里点重试会被当成"从头生成"；现在按原页签还原。
- **改尺寸后图不再只露一角**：以前把一个面板拖窄或把窗口放大后，图仍按旧尺寸的缩放待着；
  现在是按新视口重新适配并居中（可关，见上）。

# English

**Diagramon {{version}}** turns "read this diagram" into the AI panel's first read-only tab, and lets the view refit itself when the render area changes size.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **New "Explain" tab** (the 4th tab in the AI panel): a read-only reading of the current diagram —
  what it describes, how the main path flows, where the module boundaries are, which error branches or
  design risks deserve attention. **No code output, no Apply button, no edits to the document.**
  Replies live in this tab's own conversation, persisted per document and listed in History.
- **Four direct entry points**, all landing on the same action:
  - AI menu → "Explain: read-only read of the current diagram"
  - shortcut **`Ctrl+Shift+E`**
  - command palette (`Ctrl+Shift+P`) → "Explain…"
  - the "Explain" button in the preview header, or **right-click a document tab → "Explain (read-only)"**
  The empty state adds a primary button and three angle chips (what it says / main path / risks) that send
  directly.
- **`Ctrl+Shift+E` also works with the panel collapsed**: it opens the panel, switches to Explain and
  starts the reading.
- **Auto-fit when the render area resizes** (new setting, on by default, under Settings → Editor):
  after dragging the splitter, toggling the sidebar / AI panel / bottom panel, switching view modes or
  resizing the window, the diagram refits and re-centres exactly as pressing "Fit view" would. Turn it off
  and the viewport only changes on open/switch and on an explicit fit.
- **AI tab renamed**: "Chat generation" is now "Generate", matching the four actions
  Generate / Vision / Review / Explain.

### Fixes

- **"Explain what this diagram is about" no longer draws a diagram**: the suggestion chip under the
  Generate tab used to only fill the input box, and the request went out with the "draw a diagram" intent;
  it now jumps to the Explain tab and sends with the read-only intent.
- **Restored conversations retry with the right intent**: turns loaded from disk used to lose their tab,
  so retrying a Review turn was sent as "generate from scratch"; they are restored with their tab now.
- **The diagram no longer ends up half out of view after a resize**: narrowing a panel or enlarging the
  window used to leave the old zoom in place; it now refits and re-centres on the new viewport (can be
  turned off, see above).
