### 本次修复

- **渲染报错终于能选中、能复制了**：以前预览区出现「Parse error on line 3」这类报错时，
  你把鼠标拖过去选不中任何文字——因为桌面应用为了防误选（拖动画布时不会顺手把文字选上），
  全局默认禁用了文本选择，而报错框没有单独放开。现在报错原文可以正常拖选、`Ctrl+C` 复制，
  直接贴进 AI 对话或 issue 都行。
- **底部「问题 / 输出 / 转换记录 / AI 用量」面板同样放开**：渲染失败的完整报错（带行号）
  通常列在「问题」里，从那里复制更完整。
- **空态与说明文字也可以选了**：像「未渲染：源码为空」这类提示，以前同样选不中。
- 鼠标移到报错框上会变成**文本光标**（而不是拖动画布的抓手），一眼能看出这里可以选。

拖动画布时不会误选文字、界面上的按钮和菜单不会被拖动选中 —— 这些原有行为都保持不变，
只放开了**文字本身值得复制**的那几处。

# English

**Diagramon {{version}}** is a small fix: error text you can see is now error text you can copy.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Fixes

- **Render errors can finally be selected and copied**: when the preview showed something like
  "Parse error on line 3", dragging over it selected nothing — the desktop app disables text
  selection globally so that panning the canvas never accidentally selects text, and the error box
  had no exception. The error text can now be dragged over and copied with `Ctrl+C`, ready to paste
  into an AI chat or an issue.
- **The bottom "Problems / Output / Conversion log / AI usage" panel is selectable too**: the full
  render error (with line numbers) is usually listed under Problems, which is the better place to
  copy from.
- **Empty-state and hint text is selectable as well**: messages such as "not rendered: source is
  empty" used to be unselectable too.
- Hovering the error box now shows a **text cursor** instead of the canvas-panning hand, so it is
  obvious that the text can be selected.

Panning the canvas still never selects text, and buttons and menus still don't get selected by
dragging — only the places whose **text is worth copying** were opened up.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer
