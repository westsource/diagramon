### 修复

- **AI 面板拉窄后，输出内容有时不跟着变窄。** 具体表现：AI 回复里带一段长代码时，那张
  「代码卡片」保持原来的宽度不动，整个对话栏出现横向滚动条，看起来像"面板变窄了、输出框没变"。
  根因是消息正文用的是"按内容定宽"的布局，卡片里 `pre` 的一行长代码会把它的最小宽度顶到几百 px；
  而卡片本身没有加宽度上限，于是它拒绝收缩。现在消息里的**每一个块**（文本气泡、代码卡片、
  思考块、工具调用行）都被统一收在面板宽度内 —— 长代码改在卡片自己内部横向滚动，面板随拖随变。
- 顺带把这条做成验收项：真机之外的 UI 探针里加了一条"最小宽度（260px）下塞最坏代码卡片，
  对话栏不得横向溢出"的断言（未修复时实测溢出 2393px，现在 0px）。

# English

**Diagramon {{version}}** is a fix release: it only changes how message blocks are sized inside the AI panel.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Fixes

- **The AI panel's answer area sometimes refused to narrow with the panel.** In practice: when a reply
  contained a long code block, that code card kept its old width while the conversation area grew a
  horizontal scrollbar, so it looked like the panel narrowed but the output did not follow.
  The message column sizes each block to its content, and a single long line inside `pre` pushes the
  card's minimum width into the hundreds of pixels — with no upper bound the card simply would not
  shrink. Now **every block** in a message (text bubble, code card, reasoning block, tool-call line) is
  capped to the panel width, and long code scrolls inside its own card. Resize the panel and the output
  follows immediately.
- The case is now covered by an automated UI-probe assertion: at the minimum panel width (260px) a
  worst-case code card must not make the conversation area scroll horizontally (2393px of overflow
  before the fix, 0px after).
