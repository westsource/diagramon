# English

**Diagramon {{version}}** puts the font size right in the preview toolbar: each document can set its
own diagram text size, remembered per file. It also fixes the source-editor font size setting that
previously did not stick.

### ⚠️ 3.14.5 / 3.15.0 users must update manually

**One character in the update public key shipped in 3.14.5 and 3.15.0 is corrupted**, so those
clients cannot verify any update package (the updater reports `The signature verification failed`).
They will **not** be offered this release and cannot install it automatically. If you are on either
version, download and install {{version}} once by hand; automatic updates work again afterwards.
3.14.4 and older are unaffected and can update via **Help → Check for updates** as usual.

| Type | File | Notes |
|---|---|---|
| **Installer** (Windows, recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (Windows, no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.

### Highlights

- **New "Size" dropdown in the preview toolbar**: it sits on the same row as Look / Layout / Colors.
  The choice applies to the current document only, is remembered per file, and `Follow settings`
  returns to the global default.
- **Unified diagram font size setting**: Settings → Editor → Diagram font size gives Mermaid / DOT / D2
  a shared default; `0` leaves each engine's own size alone. A single diagram can still override it
  from the preview toolbar.
- **Font size affects rendering and exports only, never the source**: explicit sizes in the source
  (Mermaid `themeVariables.fontSize`, DOT `fontsize`, D2 `style.font-size`) always win; PNG / SVG
  exports pick up the current size automatically.
- **Two macOS builds**: Universal and native Apple Silicon dmgs ship with this release; both support
  in-app auto-update.
- **Linux stays included**: AppImage (in-app auto-update) and deb (system package manager).

### Fixes

- The source-editor font size setting is now **actually saved**: before, editing the input did not
  persist and reopening Settings reset it to 13.
- The source-editor font size now **actually applies to CodeMirror** immediately, including redrawing
  the error-line markers at the new line height.
- The two font-size labels in Settings are now distinct: "Source font size" changes only the editor
  text; "Diagram font size" changes only the rendered diagram.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, D2, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>
