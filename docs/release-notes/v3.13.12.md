### 本次亮点

- **drawio 配色现在覆盖整张图。** 打开已经带颜色的 drawio 再选色系，不会只改一两个节点；
  所有可见节点统一套用当前色系，原色仍留在 `dgmOriginal` 里可回退。
- **嵌套框与内层节点不再同色。** 原生 drawio 的 `swimlane` / `container`，以及 Mermaid
  转 drawio 后由导入器生成的普通矩形 subgraph 框，都按层级识别为「框」；框用更浅的
  `frame_swatch`，框内节点用对应分组色。多层嵌套逐层区分，框不会溶进节点背景。
- **画布标签的 undo 不再串。** 每次载入新的画布文档（切标签、外部替换、配色重载）
  都会清掉该承载页的 undo 栈；`Ctrl+Z` 不会再把另一个标签页的编辑撤回来。
- **大 drawio 刚打开就配色不再拿到空图。** 配色前先对齐当前文档，并等待承载页的
  `load/loaded` 确认再导出画布内容，避免把半截图写回。
- **Excalidraw 载入与配色更稳。** 配色/清除不再等一次可能超时的 `getScene` 往返；
  载入文档时先给确定视口，适应视图改用 `fitToViewport`。

### 修复

- drawio 清除配色时同时恢复 `fillColor` 与 `strokeColor`，不再只清填充、留下旧描边。
- drawio 的 `group` 结构壳不再被当作可见框上色。
- Mermaid → drawio 的 subgraph 框不再因为缺少 `swimlane`/`container` 标记而被当成普通节点，
  避免整棵嵌套子树落到最外层同一个颜色槽。
- 重跑配色是幂等的：节点、框、连线的颜色不会重复叠加或漂移。

# English

**Diagramon {{version}}** closes the remaining canvas coloring edge cases.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **drawio coloring now covers the whole diagram.** Opening an already-colored drawio and picking a
  scheme no longer changes just one or two cells; every visible node gets the scheme, while the
  original colors remain in `dgmOriginal` for a clean restore.
- **Nested frames no longer share their children's color.** Native drawio `swimlane` / `container`
  frames and the plain rectangular subgraph frames produced by the Mermaid→drawio importer are both
  detected structurally. Frames use the lighter `frame_swatch`; nodes use their group color.
  Multiple nesting levels stay visually distinct.
- **Undo no longer leaks between canvas tabs.** Loading a canvas document (tab switch, external
  replacement, palette reload) clears that carrier page's undo history; `Ctrl+Z` cannot undo edits
  from another tab.
- **Applying colors right after opening a large drawio no longer exports a blank/partial graph.**
  The current document is aligned first and the carrier's `load/loaded` confirmation is awaited
  before exporting canvas content.
- **Excalidraw loading and coloring are steadier.** Coloring no longer waits for a `getScene`
  round-trip that may time out; documents get a deterministic viewport on load and `fitToViewport`
  is used for fitting.

### Fixes

- Clearing a drawio palette restores both `fillColor` and `strokeColor`, not just the fill.
- drawio `group` shells are no longer colored as visible frames.
- Mermaid→drawio subgraph rectangles are no longer treated as ordinary nodes just because they lack
  `swimlane`/`container` markers; a nested subtree no longer collapses into the outer group's slot.
- Re-applying a palette is idempotent: node, frame and edge colors do not stack or drift.
