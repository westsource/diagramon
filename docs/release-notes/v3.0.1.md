### 本次亮点

- **启动时自动检查更新**（后台跑一次，不挡启动）：发现新版就在**状态栏亮出可点入口**
  （`⬇ 有新版本 x.y.z`），点一下即确认 → 下载 → 安装 → 自动重启。检查是**安静**的 ——
  网络抖动或"已是最新"都不会打扰你；手动点「帮助 → 检查更新」才会把三种结果都明说。
- **登录窗口的「没有账号？去官网注册」真的会打开系统浏览器**了。此前它只弹一句"已交给系统
  浏览器打开"，**实际什么都没打开**（一个假动作）。现在走系统默认浏览器打开
  `{服务地址}/register`；万一打不开，注册地址会留在窗口里可直接复制。
- **关于对话框换成新的软件介绍**：本地优先的多格式图表编辑器、实时预览 / 格式转换 / 图片导出、
  AI 生成与图像识别、自带密钥或云网关。顺带修掉一个显示问题：以前这条介绍**只在非 mock
  环境下才出现**，浏览器原型里永远看不到它。

# English

**Diagramon {{version}}** is the second public release of dev3.0 — three fixes that should always have
been the case: updates are found sooner, the registration path actually works, and the About window
describes itself honestly.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Update checks now run automatically at startup** (once, in the background, without blocking boot).
  When a new version exists, the **status bar shows a clickable entry** (`⬇ Update x.y.z available`);
  one click confirms → downloads → installs → restarts. The automatic check is **quiet**: a flaky
  network or "you're up to date" never interrupts you — only a manual
  **Help → Check for updates** spells out all three outcomes.
- **“No account? Register on the website” in the sign-in window now actually opens your browser.**
  Previously it merely flashed "opening in your system browser" and **opened nothing** — a no-op.
  It now opens `{service URL}/register` in your default browser, and if that fails the URL is left in
  the window so you can copy it.
- **The About dialog has a new product description**: a local-first multi-format diagram editor with
  live preview, format conversion and image export, AI generation and image recognition, your own key
  or the cloud gateway. A display bug went with it: the description used to appear **only outside mock
  mode**, so the browser prototype never showed it.

### Developer notes (no user impact, just worth recording)

- Releasing is now a **single entry point**, `node tools/release.mjs <version>`, with seven hard rules
  encoded in code; the repo gained `AGENTS.md` (project rules) and `docs/release-notes/` (release
  notes under version control, bilingual by contract).
- The UI probe gained a guard: the About dialog must actually render its description, and the mock
  warning must stay a **separate** box.

### About Diagramon

Local-first diagram editor for Mermaid, Graphviz DOT, drawio and Excalidraw — live preview, format
conversion, image export. AI built in: generate from text, recognize diagrams from images, bring your
own key or use the cloud gateway.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. **Anyone on 3.0.0 will see
“Update {{version}} available” in the status bar on startup** — click it to upgrade. Manual checks are
available under Help → Check for updates.

> This installer is **not yet Authenticode-signed**, so Windows SmartScreen may show a warning.
