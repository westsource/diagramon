# English

**Diagramon {{version}}** fixes a conversion defect seen in a real case: diagrams that use the
`A("label<br>(IP)")` rounded-node idiom came out garbled when converted to drawio — they now convert cleanly.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Rounded nodes whose labels contain parentheses no longer garble the whole diagram**: Mermaid lets you
  write `A("label<br>(172.16.0.1)")` — parenthesis inside a rounded node. Converting that to drawio used to
  trip the importer (labels shredded, fragments leaking into the next node, geometry in chaos). Those rounded
  nodes are now treated as **stadium shapes** before conversion, so the output is clean and complete.
- Measured on this deployment diagram: about half the nodes were garbled before; after the change, zero
  broken labels and every child vertex lands inside its parent box.

### Fixes

- **Mermaid → drawio: nodes using a rounded shape `A("label (IP)")` with parentheses in the label garbled the
  diagram**: drawio's built-in importer can't parse such a shape — its paren matching goes off. Conversion now
  rewrites only rounded labels that actually contain `(` / `)` to `A(["..."])` (the closest usable double-round
  shape); paren-free rounded nodes are left untouched, and a fidelity note is added. A regression test covering
  the real corpus was added (confirming paren-free rounded, rectangle and subroutine shapes are unaffected).

### Notes

- Top-level `subgraph` cluster bounding boxes may still overlap each other after conversion to drawio — an
  inherent limitation of drawio's importer's subgraph grouping, not a regression of this fix; it can later be
  eased with the existing "ELK re-layout" option.
