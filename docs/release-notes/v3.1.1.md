### 修复

- **「另存为」的文件类型跟着标签页走**：以前这个对话框里只有「所有文件」，也没有缺省扩展名 ——
  你把建议文件名里的后缀删掉（改名时很常见），存出来的就是一个**没有扩展名**的文件，
  下次打开会被当成 Mermaid 兜底解析：drawio / DOT / Excalidraw 的文件就此按错误格式打开。
  现在类型清单第一项是**当前标签页的格式**（如 `drawio (*.drawio)`），依次是 Mermaid / DOT 的
  等价扩展名，最后才是「所有文件」；类型清单的第一项同时是系统用来补后缀的那一项，
  所以「没写后缀」得到的一定是与内容相符的后缀。
- 建议文件名仍按当前格式的规范扩展名生成（`.mmd` / `.dot` / `.drawio` / `.excalidraw`），
  与上面那条一起生效，不再依赖"用户恰好只按回车"。

> 本应用的「保存」**不做跨格式转换** —— 要换格式请用转换中心（标签条的「转换」下拉）另开一个标签页。

# English

**Diagramon {{version}}** is a fix release: the Save-As dialog now carries a **file type**
that follows the current tab's format.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Fixes

- **The Save-As file type now follows the tab**: the dialog used to offer only "All files" and no
  default extension — so deleting the extension from the suggested name (a very ordinary thing to do
  while renaming) produced a file with **no extension at all**, which is then reopened as Mermaid.
  drawio / DOT / Excalidraw files could end up parsed as the wrong format. The type list now leads
  with the **current tab's format** (e.g. `drawio (*.drawio)`), followed by the equivalent extensions
  for Mermaid / DOT, and "All files" last. That first entry is also what the system uses to append a
  missing extension, so "no extension typed" always yields one that matches the content.
- The suggested file name still uses the current format's canonical extension
  (`.mmd` / `.dot` / `.drawio` / `.excalidraw`), so the two now work together instead of relying on
  the user pressing Enter on an untouched name.

> Saving never converts formats — to switch formats, use the Conversion Center (the "Convert"
> dropdown in the tab bar) and work in the new tab it opens.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer
