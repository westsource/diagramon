### 修复

- **手动调好的缩放与位置不再被抹掉**：以前每敲一个字都会重新按画布适应一次（换主题、
  切源码 / 分屏 / 预览也一样），你刚拖好、缩好的视图当场复位。现在自动适应只发生在两个时刻 ——
  **打开或切换到某份文档（初始化）** 与 **你显式点「适应视图」**；其余时候视口一律保持原样。
- **「适应视图」现在真的适应**：`Ctrl+0` 与命令面板里的「适应视图」以前走的是"回到 100%"，
  与它的标题、帮助里的快捷键表都对不上；现在它和预览工具条的适应按钮、双击画布同一条路，
  按画布大小把整幅图放进来。状态栏那个缩放项（提示语是"点击回到 100%"）保持原样。
- **报错不再打乱你的视图**：语法错误时只把画面临时归零，保证「无法渲染：行 3 …」这类文字
  一定落在屏幕里；你原来的缩放与位置留在账上，改好之后原样还原（不会顺手重排）。
- drawio / Excalidraw 画布不受影响：它在同一份文档里本来就不重载，编辑过程不动视口。

# English

**Diagramon {{version}}** is a fix release: the preview canvas viewport belongs to you again —
the zoom and position you set are no longer quietly reset by typing, theme switches or view-mode changes.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Fixes

- **Your manual zoom and position are no longer wiped**: every keystroke used to trigger another
  fit-to-canvas (theme switches and source/split/preview switches did too), snapping the view back
  right after you had panned or zoomed it. Auto-fit now happens at exactly two moments —
  **opening or switching to a document (initialisation)** and **your explicit "Fit to view"**;
  the rest of the time the viewport is left alone.
- **"Fit to view" now actually fits.** `Ctrl+0` and the command-palette entry used to reset to 100%
  instead, contradicting their own label and the shortcut sheet; they now take the same path as the
  preview toolbar's fit button and double-clicking the canvas, framing the whole diagram in the canvas.
  The status-bar zoom item ("click to reset to 100%") keeps its own behaviour.
- **Errors no longer disturb your view**: on a syntax error the canvas is parked at 100% only so the
  "cannot render: line 3 …" message stays on screen; your zoom and position are kept and restored
  verbatim once the syntax is fixed (no silent re-layout).
- drawio / Excalidraw canvases are unaffected: they already never reload within a document, so
  editing does not move their viewport.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. Users on an older version
will be offered this release via **Help → Check for updates** (the update package is this same
installer; its signature is in `latest.json`).

> This installer is **not yet Authenticode-signed**, so Windows SmartScreen may show a warning.
