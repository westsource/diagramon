### 本次亮点

- **改动以 diff 清单呈现**：AI 返回的代码与当前文档逐行比对，每一块（删除行 + 新增行）一个勾选框；“应用勾选的改动”只落你勾的那些块，其余保持原样。
- **多步撤销**：连续应用多次后，可以一步步退回（上限 20 步），不再只有“撤销上一次”。
- **错格式代码块直接拒绝**：当前是 Mermaid 时贴来一段 DOT，不再偷偷另开一个标签页；提示写明两边格式，让你在对应文档里应用。

### 修复

- **“应用”不再静默换文档**：格式不一致时明确拒绝（以前会新建标签页，用户以为改的是当前文档）。

### 说明

- 本版的 diff 在界面侧按行计算，不需要模型输出 patch JSON；因此 `Span` 与“模型给出的逐条 patch”留到后续版本（见交付计划 I6 状态）。

# English

**Diagramon {{version}}** lets you pick and choose AI edits: review the diff, tick the blocks you want, and step back one apply at a time.

### Downloads

| Option | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Supports **built-in auto-update**; fetches the WebView2 runtime if missing |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

Portable notes: the ZIP contains `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\` — they
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs nothing extra installed: no Node.js, no Chrome, no VC++ redistributable (the exe links the
CRT statically); only the WebView2 runtime that ships with Windows 10/11. “Check for updates” still
finds new releases, but applying one downloads the **installer** (it does not replace the portable
folder in place) — to stay portable, download the new ZIP and overwrite.

### Highlights

- **Changes as a diff list** — the AI output is compared line by line with the current document; each
  block (removed + added lines) has a checkbox. “Apply selected changes” writes only the blocks you
  ticked and leaves everything else alone.
- **Multi-step undo** — after several applies you can step back one at a time (up to 20 steps), instead
  of only undoing the last one.
- **Wrong-format code blocks are refused** — pasting DOT into a Mermaid document no longer silently
  opens another tab; the message names both formats and asks you to apply it in a matching document.

### Fixes

- **“Apply” no longer switches documents silently** — a format mismatch is now an explicit refusal
  (previously it opened a new tab while the user thought the current document changed).

### Notes

- This release computes the diff in the UI, so the model does not need to emit patch JSON; `Span` and
  model-provided per-line patches are left for a later version (see the delivery plan’s I6 status).

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid / Graphviz DOT / drawio /
Excalidraw, all editable with live preview, plus AI for generation, review and image recognition.
Rendering and validation work offline — only the AI features you explicitly use send code or images
to the upstream you choose.

Website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (usually preinstalled; the installer fetches it when missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all ship with the app

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and install. Existing users get this
