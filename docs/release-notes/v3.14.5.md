### 本次亮点

- **Linux 桌面版首发**：AppImage（可自更新）与 deb 两种形态，功能与 Windows 版一致（五种格式、画布、AI、云文档）；数据在 `~/.config/Diagramon` 与 `~/.local/share/Diagramon`。
- **云端文档不再重复开标签**：在「云端文档」侧栏点一份**已经打开**的文件，现在只会切到那个标签页 —— 不再新开一个标签页重新载入/渲染，也不会用云端正文覆盖你本地未保存的修改。
- **账户页脚两个平台统一**：退出登录改成与网页版相同的「出口箭头 + 整行左对齐」，文字色沿用客户端的常规色；红色只留在二次确认对话框里。

### 修复

- 修复重复点击同一份云端文档会多开一个标签页、并重新拉取正文的问题。

### 已知边界（Linux）

- **Wayland 下应用内截屏默认关闭**（用系统截图工具替代）：GNOME/KDE 等合成器不提供 screencopy 协议，xcap 会直接崩溃；X11 正常。wlroots 系合成器可用 `DGM_WAYLAND_CAPTURE=1` 试用（此时 overlay 只能定位在主屏）。
- 托盘图标依赖桌面环境的 appindicator 支持（GNOME 需扩展）；关窗到托盘在无托盘环境会退化为普通关闭。
- deb 没有应用内自动更新：升级请下载新版本覆盖安装。

# English

**Diagramon {{version}}** ships the Linux desktop app (AppImage / deb) and fixes two issues: reopening an already-open cloud document duplicated its tab, and the account footer looked different between desktop and web.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (Windows, recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (Windows, no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |
| **Linux AppImage** (no install) | [Download AppImage]({{appimage_url}}) (~{{appimage_size_mb}} MB) | `chmod +x` and run; **in-app auto-update supported** |
| **Linux deb** (Debian / Ubuntu) | [Download deb]({{deb_url}}) (~{{deb_size_mb}} MB) | Install with your package manager; needs WebKitGTK 4.1; **no** in-app auto-update (download the new version) |

Windows portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable — only the system
WebView2 runtime that comes with Windows 10/11.

Linux notes: the AppImage is a single file — `chmod +x Diagramon_*.AppImage` and run it; the deb suits a
fixed desktop and registers the five diagram extensions (.mmd/.dot/.d2/.drawio/.excalidraw). On Linux the
account token and AI keys live in the system keyring (Secret Service behind GNOME Keyring / KWallet) —
they are **never** written to the config directory in plain text. If no keyring is available the UI says so
instead of silently degrading.

### Highlights

- **First Linux desktop release**: AppImage (self-updating) and deb, feature-identical to Windows (five formats, canvas, AI, cloud documents); data lives in `~/.config/Diagramon` and `~/.local/share/Diagramon`.
- **No more duplicate cloud tabs**: clicking a cloud document that is **already open** in the "Cloud documents" sidebar now just switches to that tab — it no longer opens a second tab that reloads/renders again, and it will not overwrite your unsaved local edits with the cloud copy.
- **Account footer unified across platforms**: sign-out is now the same "log-out arrow + full-width left-aligned row" as the web version, using the client's regular text colour; red stays only in the confirmation dialog.

### Fixes

- Fixed reopening the same cloud document opening a duplicate tab and re-fetching its body.
- Fixed the sign-out style mismatch (icon, colour) between the desktop and web account sidebars.

### Known limits (Linux)

- **In-app screenshot is off by default on Wayland** (use your desktop's screenshot tool): GNOME/KDE compositors do not implement the screencopy protocol and xcap would crash; X11 is unaffected. wlroots-based compositors can opt in with `DGM_WAYLAND_CAPTURE=1` (the overlay can only be placed on the primary display).
- The tray icon depends on appindicator support (an extension is needed on GNOME); close-to-tray degrades to a normal close where no tray exists.
- The deb has no in-app auto-update: download the new version to upgrade.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit, or Linux x64 (Ubuntu 22.04+ / Debian 12+, WebKitGTK 4.1 required)
- Windows: WebView2 runtime (normally pre-installed; the installer downloads it if missing)
- Linux: AppImage (nothing to install) or deb via your package manager
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the package

### Install and update

Windows: download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it; users on an older
version get this release via **Help → Check for updates**. Linux: the AppImage also checks for updates

> Packages are **not code-signed**: Windows SmartScreen may warn; unsigned AppImage/deb is the norm on Linux.
