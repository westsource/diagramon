# English

**Diagramon {{version}}** makes long conversations and error fixing more controllable: you can see
how much context is being sent, act on a single turn, and ask the AI to fix the line that failed.

### Downloads

| Option | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Supports **built-in auto-update**; fetches the WebView2 runtime if missing |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

Portable notes: the ZIP contains `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\` — they
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs nothing extra installed: no Node.js, no Chrome, no VC++ redistributable (the exe links the
CRT statically); only the WebView2 runtime that ships with Windows 10/11. “Check for updates” still
finds new releases, but applying one downloads the **installer** (it does not replace the portable
folder in place) — to stay portable, download the new ZIP and overwrite.

### Highlights

- **Context budget is visible** — next to the input: “context N turns · M/limit chars”, marked
  “trimmed to budget” when over. The limits come down from Rust; the front end does not keep a second copy.
- **Single-turn actions** — the ⋯ menu on each message can regenerate, edit and resend, delete, or
  branch into a new conversation. Deleting a user turn also removes the reply right after it, leaving
  no orphan bubble.
- **“Ask AI to fix this line”** — every provable error in the Problems panel gets an action that sends
  only that line ±10 to the model. This version promises the **request scope**, not “only that line changes”.
- **Ctrl+V pastes an image** into the vision input (pasting inside the editor or canvas is untouched).

### Fixes

- **The current document is no longer sent twice** — if the last assistant turn is exactly the current
  body, it is dropped when assembling the request (cheaper long conversations).

### Notes

- Semantic review (isolated nodes / no failure branch / unexpected cycles) and structured `json_object`
  output depend on server batch S2; this release delivers the budget, single-turn actions, image paste
  and inline fix, and the review is moved to the next iteration (see the delivery plan's I5 status).

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid / Graphviz DOT / drawio /
Excalidraw, all editable with live preview, plus AI for generation, review and image recognition.
Rendering and validation work offline — only the AI features you explicitly use send code or images
to the upstream you choose.

Website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (usually preinstalled; the installer fetches it when missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all ship with the app

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and install. Existing users get this
release via **Help → Check for updates** (the update package is the installer; see `latest.json` for
its signature).
