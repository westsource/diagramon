# English

**Diagramon {{version}}** polishes layout and AI configuration: the app opens straight onto the canvas,
and custom model configuration actually works.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **The side bar is collapsed by default — you start on the canvas.** A canvas-first editor should not
  give its first column to a file tree. Open it any time from the activity-bar icons
  (Explorer / Search / Convert / Cloud / Outline) or with Ctrl+B. The activity bar stays — it is the way
  back in. **Users who manually toggled the side bar keep their choice.**
- **Custom model configuration now really works.** "AI Settings → Add model" finally adds: fill in the
  base URL, model ID and key, save, and the model shows up in the model list and the default-model
  dropdown, surviving a restart. No more editing config files by hand.

### Fixes

- **"Add model" did nothing.** The AI settings pane was rendered from saved settings while saving wrote
  a draft — the two never met, so Add/Remove silently did nothing on screen. The pane now renders the
  draft: add, remove, edit and save are all immediately visible.
- In the browser prototype, changes to the AI / Editor / Cloud settings sections were lost on reload —
  the mock backend persisted them in the wrong order. Fixed (the packaged app was never affected).

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. Users on 3.0.0 – 3.0.2 will
see "Update {{version}} available" in the status bar on the next launch — click it to open the update
window (or use Help → Check for updates). **If the download stalls**, the window's
"Download in browser" button fetches the installer directly.

> This installer is **not yet Authenticode-signed**, so Windows SmartScreen may show a warning.
