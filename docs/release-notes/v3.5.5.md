### 本次亮点

- **源码窗口的 Tab 与主流编辑器一致了**：光标在句子中间按 Tab 时，以前**整行都会右移**
  （旧实现照抄的是 CodeMirror 的 `indentWithTab`＝整行缩进，与 VS Code / JetBrains / Sublime 都不同）。
  现在空选区按 Tab 在**光标处**补空格到下一个制表位；行首按 Tab 仍是整档 4 空格（肌肉记忆不废），
  有选区时整块缩进、`Shift+Tab` 反缩进，与以前一样；一次按键仍是一个撤销步骤。
- **画布「适应视图」＝ 把所有内容框进视口并尽量放大**：
  - **drawio**：以前合成的是 `Ctrl+Shift+J`，而它在 drawio 里绑的是「双页」——按**两个页宽**的区域
    适配并居中到页面上。于是内容比页面小就缩得过分小，内容在页面框之外还会被直接切掉。
    现在按**内容框**两维适配并居中：实测同一份 260×70 的内容从 65% 变成 **475%**，
    页面框之外的单元格不再被切（旧路线底边切掉 107px）。
  - **Excalidraw**：这颗按钮以前**完全没反应**（承载页从来没暴露适配钩子），现在会真的把画布内容
    整体放进视口并居中。
  - 放大范围与另外三种格式（mermaid / DOT / D2 的 SVG 预览）一致，落在 **0.2×–30×**：
    极小的图不会放大到几百 %；比视口还大的图停在 0.2×（此时适配已到极限，界面照常告诉你这次适配过）。

### 修复

- 画布还没起来、或文档为空时，「适应视图」不再被记成"已适配"（以前会把一次什么都没做的动作记上账，

- Excalidraw 画布的「适应视图」（浮动工具栏那颗、画布双击、`Ctrl+0`）恢复可用。

# English

**Diagramon {{version}}** fixes two interactions that were never quite right: Tab in the source window no
longer shifts the whole line, and the canvas "Fit to view" finally fits the *content* (drawio used to fit
its own page box, and on Excalidraw the button was not wired to anything at all).

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Tab in the source window now behaves like every other editor.** With the caret in the middle of a
  sentence, Tab used to shift the **entire line** (the old implementation copied CodeMirror's
  `indentWithTab`, i.e. whole-line indentation — unlike VS Code / JetBrains / Sublime). Now Tab with an
  empty selection fills spaces to the next tab stop **at the caret**; at the line start it still inserts a
  full 4-space unit (muscle memory intact), a selection is still indented as a block, `Shift+Tab` still
  outdents, and one key press is still one undo step.
- **"Fit to view" on the canvas now means "put all content in the viewport, as large as possible".**
  - **drawio**: the button used to synthesize `Ctrl+Shift+J`, which drawio binds to *Two Pages* — it fits
    a **two-page-wide** area centred on the page. Content smaller than the page was zoomed far too small,
    and content outside the page box was simply cut off. It now fits the **content box** in both
    dimensions and centres it: the same 260×70 content measured 65% before and **475%** now, and cells
    outside the page are no longer clipped (the old route cut 107px off the bottom edge).
  - **Excalidraw**: this button did **nothing at all** (the carry page never exposed a fit hook); it now
    really fits the canvas content into the viewport, centred.
  - The zoom range matches the other three formats (mermaid / DOT / D2 SVG previews): **0.2×–30×** — a
    tiny diagram is never blown up to hundreds of percent, and a diagram larger than the viewport stops at
    0.2× (at that point the fit is already at its limit, and the UI still reports that it fitted).

### Fixes

- "Fit to view" is no longer recorded as done when the canvas is not up yet or the document is empty
  (previously such a no-op was marked as fitted, so it was never retried).
- The Excalidraw "Fit to view" entry points (the floating toolbar button, double-clicking the canvas,
  `Ctrl+0`) work again.
