### 本次亮点

- **启动后自动恢复登录状态**：以前刚打开应用时界面会先显示「未登录」，得手点一下「账户」才变回来
  —— 那是把"还在检查"当成了"未登录"。现在启动自己就把登录状态恢复到位：侧栏账户、状态栏的模型名、
  AI 面板的可用模型都会跟着自己更新，网络没热起来时还会自动重试。
- **中断 AI 生成 = 停止方块**：生成过程中那颗按钮原来是 X，现在是标准的「停止」方块（红底），
  鼠标悬停写着「停止生成」，点一下即中断这一轮。

### 修复

- **启动后要手点「账户」才显示已登录**。根因是把"启动那次检查还没回来"当成了"未登录"：
  活动栏「账户」按钮据此直接弹登录窗（会话其实是好的），而状态栏的模型名与 AI 面板没有订阅云状态变化，
  一旦先渲染成「未配置 / 没有可用模型」就再也不会自己更新；另外那次检查失败时没有重试。
  现在："没查过"与"查完是未登录"分开（没查完时账户视图显示「正在检查登录状态…」）、
  同一时刻只跑一次检查（顺带避免并发令牌轮换）、启动失败会退避重试、状态栏与 AI 面板都会随云状态重渲染。
- **中断生成的按钮是个 X**：语义不清（像"关闭"），现在换成停止方块，标题也从"已取消"改成"停止生成"。

# English

**Diagramon {{version}}** fixes "sign-in only comes back after clicking Account" and turns the
interrupt button into a proper stop square.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **Your sign-in state comes back on its own at launch.** The window used to greet you with
  "not signed in" until you clicked Account — that was an unfinished startup check being treated as
  a real "signed out". The account panel, the model name in the status bar and the AI panel's model
  list all follow the cloud state now, and a startup failure is retried instead of sticking.
- **Interrupting generation is a stop square.** The button shown while the AI is streaming used to be
  an X; it is now the standard stop glyph (on the red button) with a "Stop generating" tooltip, and it
  cancels the current turn in one click.

### Fixes

- **Sign-in only appeared after clicking "Account"** — the startup check was still in flight, yet its
  placeholder value (signed out) was used as fact: the activity-bar Account button popped the login
  dialog for a perfectly valid session, and two widgets (status-bar model chip, AI panel) never
  subscribed to cloud-state changes, so once they painted "not configured / no models" they never
  updated. Startup failures were not retried either. Now "not checked yet" is distinct from
  "checked, signed out" (the account view says "Checking sign-in status…" meanwhile), concurrent
  checks share a single request (which also avoids concurrent token rotation), a failed startup check
  backs off and retries, and both widgets re-render whenever the cloud state changes.
- **The interrupt button was an X**, which reads like "close" rather than "stop"; it is now a stop
  square and its tooltip says "Stop generating" instead of the status-y "Cancelled".

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>
