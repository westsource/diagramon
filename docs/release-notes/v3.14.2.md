### 本次亮点

- **drawio 转换更可靠**：冷启动时不再在承载页就绪前提前判失败；先暖机、等 `load` 确认再导出，转换结果必须含实际节点，避免转出一张空画布。
- **转换标记不再被重载吃掉**：转换期间/之后重载承载页或换窗口，待消费的转换任务仍然生效（未消费时不会被当成「已加载」提前返回）。
- **模具库不再干扰转换**：stencils 只在转换成功后或用户点开形状面板时按需加载；转换期间不加载 —— 之前正是它把转换卡在半路。
- **云端文档标题正确**：打开云端文件后标签页显示服务端给的名字；切标签、关掉重开都保持，不再变成「未命名-N」。保存到云端时改名也会同步进会话。
- **转换链路的兜底**：转换描述符（descriptor）未生效时自动重发；转换实现回退到已知可用的那份，再逐条补回护栏，不再在两条实现之间来回漂。

### 修复

- 修复打开云端文档后标签页变成「未命名」，且切走再切回会再次变回未命名的问题。
- 修复 drawio 冷启动转换偶发「承载页未就绪 → 直接失败」。
- 修复转换标记在承载页重载/窗口切换后丢失，导致转换卡在空白文档。
- 修复转换结果只有空白页、没有节点也当作成功的问题。
- 修复 drawio 模具库延迟加载把正在进行的转换挤掉的问题。

# English

**Diagramon {{version}}** fixes several drawio conversion paths that "looked converted but weren't", and keeps the server-provided name when you open a cloud document.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still finds new versions, but updating downloads the **installer**
(it does not replace the portable folder in place) — to stay portable, grab the new ZIP manually.

### Highlights

- **More reliable drawio conversion**: a cold start no longer fails before the host page is ready; it warms up first and waits for the `load` confirmation before exporting, and a conversion must contain real nodes — no more successfully converting to a blank canvas.
- **Conversion markers survive reloads**: reloading the host page or switching windows mid-conversion keeps the pending conversion alive (an unconsumed one is no longer treated as "already loaded").
- **The stencil library no longer gets in the way**: stencils load on demand only after a successful conversion or when you open the shapes panel — loading them during a conversion was what stalled it.
- **Correct titles for cloud documents**: opening a cloud file shows the server-provided name; it stays put when switching tabs and after closing/reopening, instead of turning into "Untitled". Renaming on save-to-cloud is persisted too.
- **Safety nets in the conversion path**: the conversion descriptor is re-sent if it did not take effect, and the implementation is back on the known-good version with the guards reapplied, instead of drifting between two implementations.

### Fixes

- Fixed cloud documents opening as "Untitled", and reverting to "Untitled" again after switching tabs.
- Fixed drawio conversion on cold start occasionally failing because the host page was not ready yet.
- Fixed the conversion marker being lost after a host-page reload or window switch, leaving the conversion stuck on a blank document.
- Fixed a conversion with no nodes being treated as success.
- Fixed the drawio stencil library being loaded late and starving an in-flight conversion.
