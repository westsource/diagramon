# 中文

**Diagramon {{version}}** 修的是 3.0.1 的一个体验硬伤：点「下载并安装」之后**看不出到底在不在下载**。

### 修复

- **下载进度就在那个窗口里显示，窗口不再关掉**：点「下载并安装」后，同一个窗口从
  "更新说明"切换成"正在下载 42%"（带进度条）；下完自动显示"更新完成，正在重启…"。
  下载中关掉窗口**不会中断下载**，状态栏那一项会继续报进度，**点它就能回到这个窗口**。
- **卡住会被发现**：超过 20 秒没有新数据，窗口里会写明「下载卡住（已收 12.3 MB）」并
  多出一个 **「用浏览器手动下载」** 按钮 —— 直接调系统浏览器下载安装包，绕开客户端这条链路。
- **3.0.1 的问题到底是什么**：那时进度只往状态栏消息里写一句"正在下载更新…"，而状态消息
  **4.2 秒后会自动恢复成"就绪"**；同时底层插件在**收到第一个数据块之前不发任何事件**
  （`Started` 就是第一块），也没有下载超时 —— 于是连接卡在建连阶段时，用户看到的就是
  "闪一下就没动静了"。现在进度是**常驻**的（窗口里 + 状态栏那一项），并且有卡住检测。

# English

**Diagramon {{version}}** fixes a rough edge in 3.0.1: after clicking “Download & install” there was
**no way to tell whether it was actually downloading**.

### Fixes

- **Progress now lives in that window, and the window no longer closes.** Clicking
  “Download & install” turns the same window from “what's new” into “Downloading 42%” (with a progress
  bar); it then reads “Update done, restarting…”. Closing the window **does not stop the download** —
  the status-bar item keeps reporting progress, and **clicking it brings the window back**.
- **Stalls get noticed.** After 20 seconds with no new data the window says
  “Download stalled (12.3 MB received)” and grows a **“Download in browser”** button that fetches the
  installer with your system browser, bypassing the client's own path.
- **What was actually wrong in 3.0.1:** progress was written only into the status *message*, and that
  message **auto-reverts to “Ready” after 4.2 seconds**; meanwhile the underlying plugin emits **no
  event at all before the first data chunk arrives** (`Started` *is* the first chunk) and has no
  download timeout — so when the connection stalled during connect, all the user saw was a blink and
  then nothing. Progress is now **persistent** (in the window *and* the status-bar item) and monitored
  for stalls.

### About Diagramon

Local-first diagram editor for Mermaid, Graphviz DOT, drawio and Excalidraw — live preview, format
conversion, image export. AI built in: generate from text, recognize diagrams from images, bring your
own key or use the cloud gateway.

Official website: <https://www.diagramon.com>

### Requirements

- Windows 10 / 11 64-bit
- WebView2 runtime (normally pre-installed on Windows 10/11; the installer downloads it if missing)
- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer

### Install and update

Download [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) and run it. On 3.0.0 / 3.0.1 the status
bar will show “Update {{version}} available” — click it to open the update window (or use
Help → Check for updates). **If the download stalls**, the window's “Download in browser” button grabs
the installer directly.

> This installer is **not yet Authenticode-signed**, so Windows SmartScreen may show a warning.
