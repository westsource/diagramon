### 本次亮点

- **改图不再返回「半张图」**。客户端「应用到编辑器」是把回复里的代码**整段替换**进正文的，
  而改图的提示词过去写着「不要重写整张图…不要重复贴出源码」，模型于是只回 diff/片段，
  落进编辑器就只剩一段，Mermaid 解析必失败。现在两端都按全文走：
  **发送整篇源码**，并要求**返回修改后的完整源码**（未改动的部分原样保留）。
- **「让 AI 改这段」也带全文**。以前只把选中的那段当上下文发出去，应用后文档只剩那一段；
  现在选区只作为「这次只改这一段」的说明，全文照样上行，返回的也是完整图。
- **应用取最后一个代码块**。模型常先贴一版再贴修正版，过去应用的是第一块；
  现在与内部提取同口径取最后一个非空围栏。
- **自动保存默认关闭**。写盘不可逆（AI 应用、批量替换都会改正文），默认静默保存等于替你按 Ctrl+S。
  现在默认只在 Ctrl+S / 另存为时落盘；想要随手改随手存，可在 **设置 → 编辑器 → 自动保存** 打开，
  延时 500–60000 ms 可调。
  （升级不会擅自关掉你此前显式开启的自动保存；它只在设置里**没有**这个字段时按关处理。）

### 修复

- 设置页「自动保存」在字段缺失时显示为开，与实际默认不一致。

# English

**Diagramon {{version}}** fixes two things: AI edits corrupting your document, and the app writing to disk without your consent.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still works in the portable build, but updates are delivered as the **installer**
(it never patches the portable folder in place) — download the new ZIP to keep using it.

### Highlights

- **AI edits no longer return half a diagram.** "Apply to editor" replaces the whole body with the
  code block from the reply, while the review prompt used to say "don't rewrite the diagram…
  don't repeat the source" — so the model returned a diff or fragment, which broke the document and
  the Mermaid parse. Both sides now work on the full text: the **whole source is sent**, and the model
  must **return the complete modified source** (untouched parts kept verbatim).
- **"Ask AI to edit this selection" also sends the full document.** Previously only the selection
  went up as context, and applying left the file with just that fragment. The selection is now only
  an instruction ("change only this part"); the full source still goes up and comes back complete.
- **Apply takes the last code block.** Models often print one version and then a corrected one;
  apply used to take the first block. It now matches the internal extractor (last non-empty fence).
- **Autosave is off by default.** Writing to disk is irreversible (AI apply and bulk edits change the
  body), so a silent autosave is the app pressing Ctrl+S for you. Files are now written only on
  Ctrl+S / Save As; turn **Settings → Editor → Autosave** on for the old behaviour (delay
  500–60000 ms). Upgrading will not silently turn off autosave you had explicitly enabled — it is
  treated as off only when the setting is absent.

### Fixes

- Low Mermaid parse success after AI edits: the prompt steered the model into returning only the diff.
- "Ask AI to edit this selection" truncated the document to the selection on apply.
- The Settings autosave switch showed "on" when the field was missing, disagreeing with the default.
