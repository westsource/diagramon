### 本次亮点

- **鹰眼导航**：预览右下角新增整幅图的总览与当前视口框，点击或拖动即可定位。文本格式（Mermaid / DOT / D2）
  直接从渲染出的 SVG 取轮廓，drawio / Excalidraw 由承载页提供内容框与视口；它**只移动视口**，
  不改正文、不标脏、不进导出。
- **鹰眼开关**：预览顶栏新增按钮，设置里也有「显示鹰眼导航」（默认开启）。没有可渲染内容时按钮自动隐藏；
  画布型格式的右下角缩放条与鹰眼共用同一套边距，不再互相遮挡。
- **macOS 原生标题栏**：macOS 桌面版改用系统红黄绿交通灯（`TitleBarStyle::Overlay`），自绘窗口按钮退场并给系统按钮留位。
  网页版与 Windows / Linux 桌面版保持原样。
- **D2 引擎在 Safari 27 上可用**：WebKit 的 worker 栈较小，D2 的 Go/WASM 初始化会因 goldmark 正则递归溢出而失败。
  现在首次编译失败会自动退化到同源代码的主线程执行路径；CSP 只放行 `script-src blob:`，没有放宽到 `unsafe-eval`。

### 修复

- D2 在 Safari 27 / macOS 26+ 的 WebKit 下一直停留在「加载中」或报引擎错误，现在会正常渲染。
- 纯粹的外观设置（例如鹰眼开关、字号）不再触发整张图重排，切换时预览不闪。
- macOS 上标题栏不再出现「自绘按钮 + 系统按钮」两套窗口控件。

# English

**Diagramon {{version}}** adds an overview minimap to the preview, restores the native macOS title bar, and fixes D2 engine startup on Safari 27.

### ⚠️ 3.14.5 / 3.15.0 users must update manually

**One character in the update public key shipped in 3.14.5 and 3.15.0 is corrupted**, so those
clients cannot verify any update package (the updater reports `The signature verification failed`).
They will **not** be offered this release and cannot install it automatically. If you are on either
version, download and install {{version}} once by hand; automatic updates work again afterwards.
3.14.4 and older are unaffected and can update via **Help → Check for updates** as usual.
See the [3.15.1 fix notes](https://github.com/westsource/diagramon/releases/tag/v3.15.1).

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.

### Highlights

- **Overview minimap**: the lower-right of the preview now shows the whole diagram plus a viewport frame;
  click or drag to jump. Text formats (Mermaid / DOT / D2) take their outline from the rendered SVG, while
  drawio / Excalidraw provide the content box and viewport from their host page. It **only moves the viewport** —
  it never edits the document, marks it dirty, or appears in exports.
- **Minimap toggle**: a new preview toolbar button and a “Show the overview map” setting (on by default).
  The button hides itself when there is nothing to render; the canvas zoom bar and the minimap now share
  one bottom offset, so they no longer overlap.
- **Native macOS title bar**: the macOS desktop build uses the system traffic lights (`TitleBarStyle::Overlay`),
  the custom window buttons step aside, and the title area reserves room for the system controls.
  The web build and Windows/Linux desktop builds are unchanged.
- **D2 engine works on Safari 27**: WebKit's worker stack is small enough that D2's Go/WASM init fails on a
  goldmark regex recursion. A failed first compile now falls back to a same-source main-thread path; the CSP
  only gains `script-src blob:` — `unsafe-eval` stays closed.

### Fixes

- D2 no longer gets stuck on “loading” or reports an engine error in Safari 27 / macOS 26+ WebKit.
- Purely visual settings (the minimap toggle, font size) no longer schedule a full diagram re-render, so the preview doesn't flash.
- macOS no longer shows both custom and system window controls.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, D2, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>
