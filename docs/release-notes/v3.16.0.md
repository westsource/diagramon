### 本次亮点

- **AI 增强转换（可选，默认关）**：转换结果有损或有错时，入口才会出现（还要已配置模型、目标是文本格式）。
  一次初改 + 最多 3 轮校正，逐轮提示「第 N 次修正 / 剩余 M 次」；连续两轮同样错误会提前止损，不白烧额度。
  成功就另开标签页，失败保留本地结果并如实说明，不会给你一个空标签。
  首次使用会先提示「要外发什么」，可取消；调用计入 AI 用量。
- **转换完成后做一次数量对账**：自动数一遍节点与连线，少了就提示「少 N 个节点、M 条连线」。
  文本目标缺失算失败（可进入 AI 回灌）；drawio / Excalidraw 的缺失属于引擎表达力差异，只提示不阻塞。
  哪一侧数不出来就明说「对不了账」，不假装对得上。
- **统一校验层**：五种格式一个入口校验 —— Mermaid / DOT 给真实行列，D2 走随包 wasm 真编译，
  drawio / Excalidraw 做结构校验；引擎未就绪或文件过大时明确标「降级」，不把「没校验」当成「通过」。
- **设置里新增开关**：`转换有损时允许用 AI 增强（默认关）`，附入口条件与额度说明。

### 修复

- **Mermaid 转 DOT / D2 不再被常见写法整份卡死**：加长连接件（`===>` / `--->` / `-..->`）、
  `A --> B & C` 多目标、`subgraph id ["标题"]` 与「连到 subgraph」的边现在都能转。
  这类文件以前会在报错行整份失败（真实语料里四个构造同时出现）。
- **跨平面/跨容器的边不再多出空节点**：subgraph 到 subgraph 的连线改成落在簇边界上。
- **转换窗口里的报错可以复制**：报错文字可选中，旁边还加了「复制」按钮；保真度说明与底栏文字同理。

# English

**Diagramon {{version}}** adds a safety net to conversion: when the result is lossy or outright fails, **your own configured model** can repair it — and a count check decides whether the repair actually worked.

### Downloads

| Type | File | Notes |
|---|---|---|
| **Installer** (recommended) | [`Diagramon_{{version}}_x64-setup.exe`]({{setup_url}}) (~{{setup_size_mb}} MiB) | Enables the **built-in auto-update**; if WebView2 is missing the installer downloads the runtime |
| **Portable** (no install) | [`Diagramon-{{version}}-win-x64.zip`]({{zip_url}}) (~{{zip_size_mb}} MB) | Unzip anywhere and run `diagramon.exe`; uninstall = delete the folder |

About the portable build: it ships `diagramon.exe` + `WebView2Loader.dll` + `ui\` + `assets\`, and those
**must stay together** (the `ui\` and `assets\` trees are read from disk, not embedded in the exe).
It needs **nothing extra installed**: no Node.js, no Chrome, no VC++ redistributable (the CRT is
statically linked) — only the system WebView2 runtime that comes with Windows 10/11.
"Check for updates" still works in the portable build, but updates are delivered as the **installer**
(it never patches the portable folder in place) — download the new ZIP to keep using it.

### Highlights

- **AI-assisted conversion (optional, off by default).** The entry appears only when it applies: the
  conversion is lossy or failed, a model is configured, and the target is a text format. One initial
  rewrite plus at most 3 correction rounds, with "attempt N / M left" progress; two identical failures
  in a row stop early so you do not burn quota. Success opens a new tab; failure keeps the local result
  and says so — never an empty tab. The first run shows exactly what will be sent (cancellable), and
  calls count toward your AI usage.
- **A count check after every conversion.** Nodes and connections are counted and compared; if the
  result is short you get "N nodes / M connections missing". A shortfall on text targets counts as a
  failure (and can be fed back to the model); on drawio / Excalidraw it is an engine expressiveness gap,
  so it is only reported. When one side cannot be counted, it says so instead of pretending to match.
- **One validation layer** for all five formats: Mermaid / DOT report real line and column, D2 actually
  compiles with the bundled wasm, drawio / Excalidraw get structural checks. When an engine is not ready
  or a file is very large, the result is explicitly marked degraded — "not validated" is never reported
  as "passed".
- **New setting:** "Allow AI enhancement when conversion is lossy (off by default)", with the entry
  conditions and quota note.

### Fixes

- **Mermaid → DOT / D2 no longer dies on common syntax**: longer connectors (`===>`, `--->`, `-..->`),
  `A --> B & C` multi-target edges, `subgraph id ["title"]`, and edges that connect subgraphs all
  convert now. Such files used to fail as a whole at the offending line.
- **No more phantom nodes for container-to-container edges**: subgraph → subgraph links are clipped to
  the cluster border.
- **Errors in the conversion dialog can be copied**: the text is selectable and there is a Copy button;
  the same applies to fidelity notes and the footer text.

### About the version number

This release jumps from **3.9.1 straight to 3.16.0**: the numbers `3.10.0`–`3.15.0` are already
occupied by tags of an internal experiment line (on an archived branch, never published as a
Release). Skipping them avoids moving historical tags or colliding with them; features and the
update chain are unaffected.

### About Diagramon

Diagramon is a **local-first** multi-format diagram editor: Mermaid, Graphviz DOT, drawio and Excalidraw
can all be edited with live preview, with AI assistance for generation, review and image recognition.
Rendering and validation work with no network at all — code or images reach a model only when you
actively use AI, and then only the endpoint you chose.

Official website: <https://www.diagramon.com>

- **No** Node.js, Chrome or VC++ redistributable needed — the canvas runtimes and front-end assets all
  ship inside the installer
